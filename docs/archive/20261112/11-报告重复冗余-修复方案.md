## 一、问题清单

### 2.1 「离秋招还有约三年」出现 6 次

| 位置 | 原文 |
| --- | --- |
| hero.summary | 「离秋招还有约三年」 |
| gap.paragraphs | 「离秋招（大四上学期 9—11 月）还有约三年」 |
| roadmap.subtitle | 「到秋招还有约 三年」 |
| section 标题 | 「秋招这个时间窗离你还有约三年」 |
| section 正文 | 「距离约三年」 |
| section 标题 | 「三年后秋招那几个月的样子」 |

**原因**：`deadlineFact()` 的结果同时进了 hero 摘要、gap lines、roadmap subtitle，AI 又抄进两个 section 的标题和正文。系统没有任何跨模块去重。

**修复**（推荐 2）：
1. 只保留 roadmap 的 `subtitle` + gap 的「关键时间窗」两处；hero 摘要不写时间；
2. 或在 `contentProblems` 里加一条：全报告「还有约 X（时间）」出现次数 ≤2，超出判失败重写；
3. section 标题禁止重复系统已给过的时间事实（写进 `outputContract()`）。

### 2.2 「每周约 5 小时，到秋招约 736 小时」出现 2 次

gap 的「按你现在的英语投入」一行 + 英语 section 正文。`hoursLine` 同时进了 `gapLines()` 和 `roadmapBlock()` 的 subtitle，英语模块 data 里也有同一组数字。

**修复**：`gapLines()` 不再输出英语投入（留给 roadmap + 英语 section）；或英语 section 的 prompt 明确「不要再重复总时长，只写怎么补」。

### 2.3 目标城市整串重复 5+ 次

「新一线（杭州、成都、武汉、西安等）」在 gap、scorecard、jobmap、checklist、两个 section 里整串出现。

**修复**：`resolveTargetCity()`（`shared/src/doc.ts:51-91`）已经能落到具体城市并带 `note`；展示统一用该具体城市 + 一句依据，不要再回抄答案原文。

### 2.4 「缺一段和目标方向对得上的经历」出现 3 处

scorecard 的 practice note、jobmap 的 `fit`、每张招聘卡的 `missing`。

**修复**：这句话只在 gap 或 scorecard 出现一次；岗位卡里改成具体字段（「这条原文要实习，你没有」），不要复述整句。

### 2.5 每条过期岗位下都刷一遍「时效：这是 2024 年的公告」

`jobMatch()` 给每条 stale 岗位都塞一条 `missing`（`shared/src/doc.ts:661-665`），卡片逐条渲染，三张卡刷三遍。

**修复**：时效提示提到方向级/块级一次（方向副标题或 `sources` 上方），卡片里只留「（信息较早）」标签。
