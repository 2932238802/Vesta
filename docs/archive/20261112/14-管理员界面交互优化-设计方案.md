# 管理员界面交互优化 · 设计方案

> 版本：v1.0（2026-11-12）　状态：**已完成**
> 对应产品版本：**v1.61**（当前基线 v1.60）
> 一句话：删掉不用的「咨询预约」、把设置收进一个分组、名单页改名，并把后台各页的页头 / 工具条 / 保存 / 确认弹窗统一起来。

---

## 一、背景与决策

后台侧栏原有 11 个入口（问卷 7 + 咨询 3 + 简历 1），存在四类问题：

1. 「咨询预约」基本用不上，却占了侧栏和首页统计卡；
2. 「问卷设置 / 报告设置 / AI 分析规则」和日常名单操作混在「问卷」组里；
3. 列表页（邀请链接、学员名单、答卷详情）没有页面标题，各页页头、工具条、空状态各写一套；
4. 保存按钮滚动后跑出视野，删除仍用浏览器原生 `confirm/prompt`，未保存修改会在部分页面静默丢失。

**用户确认的决策（2026-11-12）**

| 项 | 决策 |
| --- | --- |
| 咨询预约 | 删掉侧栏栏目与页面；报告页的领取/预约表单保留，数据仍在「学员名单」和答卷详情可见 |
| 设置 | 侧栏新增「设置」组：问卷设置 / 报告设置 / AI 分析规则，三个独立页面，顶部加统一的设置切换条 |
| 名单页改名 | 「答卷与名单」→「学员名单」 |
| 交互优化 | 四项全做：统一页面骨架 + 吸顶工具条、名单表格更好用、统一保存体验、危险操作统一确认 |

**范围外**：不重做视觉风格；不改问卷 / 报告业务口径；不做后端数据迁移；旧报告不重新生成。

## 三、共享交互组件

目录沿用现有扁平结构 `web/src/components/`。

### 3.1 `AdminPageHeader.vue`

- props：`eyebrow?: string`、`title: string`、`subtitle?: string`、`dirty?: boolean`。
- slots：`actions`、`meta`。
- 输出 `.page-head / .page-title / .page-sub / .head-actions`；`dirty` 时显示「未保存」chip。
- 把上述类从各页 scoped 样式提升到 `web/src/styles.css`（限定 `.admin` 作用域，避免影响公开页），同时把 `.state-line`、`.empty-title` 提升为全局。

### 3.2 `SettingsNav.vue`

- 无 props，内部用 `useRoute()` 判断当前项；三个 `RouterLink`。
- 由 `AdminLayout` 在 `<main>` 内、`<RouterView />` 前条件渲染（`route.meta.settings`）。
- 样式是**胶囊式分段控件**，与页内已有的下划线 `.tabs` 区分，避免两层页签混淆；移动端横向滚动。

### 3.3 `SaveBar.vue`

- props：`dirty: boolean`、`saving?: boolean`、`saveLabel?: string`、`discardLabel?: string`、`message?: string`；emits：`save`、`discard`。
- 仅 `dirty || saving` 时显示，`position: fixed` 贴在内容区右下角（`right: 28px; bottom: 20px`，宽度 `min(560px, ...)`），长页滚动时也始终可见；移动端左右贴边并留底部安全区。
- 使用页：SurveyEditor、ReportEditor、SkillEditor、SubmissionDetail、ConsultWorkspace（保存全部模块）。
- 页头只保留次要动作（预览、新建模板、打开报告等），不再放保存按钮，避免重复按钮。

### 3.4 `ConfirmHost.vue` + `useConfirm.ts`

- `confirmAction({ title, message?, confirmText?, cancelText?, danger? }): Promise<boolean>`
- `promptAction({ title, message?, input: { label, value?, placeholder?, maxlength?, required? } }): Promise<string | null>`
- 模块级 FIFO 队列；`ConfirmHost` 挂在 `App.vue`（`<RouterView />` 外），路由切换时对话框不被卸载。
- 基于 `Modal.vue`，`z-index` 高于普通弹窗；输入框自动聚焦并全选，Enter 确认、Escape 取消。
- 替换全部 `window.confirm` / `confirm` / `window.prompt`；`useUnsavedChanges` 的路由离开守卫改为 `await confirmAction(...)`，`beforeunload` 因浏览器限制仍用原生确认。

### 3.5 `RowMenu.vue`（名单行操作）

- 触发按钮「更多 ⋯」；菜单 Teleport 到 body、`position: fixed` 按触发按钮定位，滚动时关闭，避免被表格 `overflow` 裁剪。
- 点击外部 / Escape 关闭；`role="menu"`，上下键移动。

### 3.6 `useHotkeys.ts`

- `useSaveHotkey(handler, enabled?)`：`Ctrl/Cmd + S` 保存并 `preventDefault`。
- `useSlashFocus()`：`/` 聚焦当前页带 `data-admin-search` 的搜索框，忽略输入框、textarea、select、contenteditable；Escape 关闭菜单由 `RowMenu` / `Modal` 各自处理。

### 3.7 `Modal.vue` 增强

- 新增可选 props：`zIndex?`、`closeOnOverlay?`。
- 模块级打开栈：只有最上层处理 Escape / Tab；body 滚动锁用计数而不是布尔。
- 打开时记录 `document.activeElement`，聚焦面板内首个可聚焦元素；Tab 循环；关闭后若原元素仍 `isConnected` 则还原焦点；`aria-labelledby` / `role="dialog"`。

> 统一 `useToast` 作为顺手项：模块级单例 + 计时器，替换各页重复的 `toast` ref；时长统一 2.2s。若迁移风险偏大，可只改时长，不阻塞本轮。

## 四、页面迁移

### 4.1 学员名单（`Submissions.vue`）

- 顶部 `AdminPageHeader`：eyebrow「学员」、title「学员名单」，导出 CSV 放 actions。
- 工具条桌面端吸顶（`@media (min-width: 901px)`，`top: 0`），移动端不吸顶，避免和移动端吸顶导航重叠。
- 选中行时工具条切换成 `.selection-bar`：已选计数、移到分组、批量删除、取消选择。
- 表格改为单一 `overflow: auto` 滚动容器（桌面端 `max-height: calc(100vh - 230px)`），`thead th` 吸顶。
- 行点击 / Enter 打开答卷详情，仅 `row.detailPath` 存在的行可点；`RowMenu` 触发按钮 `@click.stop`，处理函数再用 `event.target.closest('a,button,input,select,textarea,label,[data-row-ignore],[role="menu"],[role="menuitem"]')` 兜底，复选框、状态下拉、链接不会误触发行跳转。
- 操作列只留状态下拉；「查看答卷」由行点击承担，其余操作收进 `RowMenu`，危险项标红。
- 搜索框加 `data-admin-search`，placeholder 提示「（/ 搜索）」。
- 6 处原生确认（含分组改名 `prompt`）改为共享确认 / 输入弹窗。

### 4.2 其他列表页

- `Invites.vue`：加页头；CTA 改「去学员名单查看」。
- `SubmissionDetail.vue`：返回链接改「← 返回学员名单」；页头迁移；删除确认替换；保存改由 `SaveBar`，并接入 `useUnsavedChanges`。
- `ResumeCollection.vue`、`ConsultCollections.vue`：页头迁移，工具条桌面端吸顶。
- `ConsultCollections.vue`：卡片由「仅双击打开」改为「单击打开 + 键盘 Enter」，双击不再需要。
- `ConsultWorkspace.vue`：页头迁移；`dirty = 任一 dirtySections`，`SaveBar` 文案「保存全部修改 / 放弃修改」，按编辑时的快照逐个保存，失败时停止并提示；已保存的模块服务端已生效，不整体回滚；接入 `useUnsavedChanges`。
- `ConsultPurposes.vue`：仅页头迁移，不动画布逻辑。
- `ConsultCollectionDetail.vue`：只替换删除确认，文章式头部保留。

### 4.3 设置三页

- `SurveyEditor.vue` / `ReportEditor.vue` / `SkillEditor.vue`：页头迁移（eyebrow 统一「设置」），移除页头保存按钮（保留「未保存」chip），接 `SaveBar` 与 `Ctrl/Cmd+S`。
- 「放弃」用初始快照回滚（Survey / Report 已有 `initialJson`；Skill 用进入编辑时的快照）。
- `SkillEditor` 的「保存 / 启用 / 删除」仍留在编辑卡片内，`SaveBar` 只负责当前模板内容的保存。
- 三个页面共享 `AdminLayout` 渲染的 `SettingsNav`；页内原有下划线页签保留。

## 六、风险与回滚

- **页头与 SaveBar 重复保存**：页头只留次要动作，逐页走查确认。
- **原生 confirm 改异步**：调用函数改 `async/await`；事件绑定不受影响。
- **Modal 叠加**：必须做打开栈与 body-lock 计数，否则 Escape 会同时关两层。
- **表格嵌套滚动 + 吸顶**：用同一个 `overflow: auto` 容器承载 sticky 表头；移动端限制最大高度。
- **行点击误触**：控件 `@click.stop` + `closest()` 双重保护。
- **吸顶与移动端导航重叠**：吸顶只在桌面断点生效。
- **异步路由守卫**：`onBeforeRouteLeave` 支持 `Promise<boolean>`；`ConfirmHost` 挂在 `App.vue`。异常时回退原生 `confirm`（只改 `useUnsavedChanges.ts`）。
- **与「13-前端拆包与巨型文件拆分」并行**：`router.ts` 已改为路由懒加载，删预约时同步删对应懒加载项；若后端已拆成 `server/src/routes/admin/*`，预约路由去 `submissions.ts` 删。
- **回滚**：纯前端页面 / 路由 / 样式改动 + 一个无消费方的后端路由删除，`git revert` 对应提交即可；不涉及数据迁移。
