## CR-016 拆分巨型文件（v2.01 第一批）

- **类型**：重构
- **问题与价值**：三个文件超过 600 行硬线，改动风险高、阅读成本大：
  - `server/src/routes/consult/runs.ts` 1293 行
  - `web/src/views/ReportView.vue` 1210 行
  - `server/src/db/migrations.ts` 725 行（已到软线，继续加迁移前必须先拆）
- **目标**：按职责拆分，入口文件变薄；**行为、接口、数据、样式输出完全不变**。
- **成功指标**：
  - 三个原文件都降到 400 行以内（或只保留入口装配）。
  - 新增文件 ≤400 行。
  - `npm run verify` 全绿；关键页面与接口回归通过。
  - `check:size` 基线随之下调。
- **验收标准**：

  - `AC-016-1` `server/src/db/migrations.ts` 拆为入口 + 若干模块（列补齐、问卷升级、咨询种子、分数线迁移）；`runMigrations()` 对外签名与执行顺序不变；全新库与既有库启动结果一致。
  - `AC-016-2` `server/src/routes/consult/runs.ts` 拆为路由装配 + 按职责的处理器（CRUD / 章节 / 导出 / 重新生成等）；所有 `/api/admin/consult/runs*` 路径、方法、状态码、响应结构不变。
  - `AC-016-3` `web/src/views/ReportView.vue` 拆为页面骨架 + 子组件/样式文件；报告渲染、打印、主题、交互与拆分前一致。
  - `AC-016-4` 三个原文件均 ≤400 行，新增文件 ≤400 行；`check:size` 通过并下调基线。
  - `AC-016-5` `npm run verify` 全绿；咨询跑批接口、报告页、迁移启动做回归。
  - `AC-016-6` 不改变任何对外接口、数据表、字段、页面文案与样式表现；无新增依赖。
- **范围**：上述三个文件及其拆分产物；必要的 import 调整；`scripts/file-size-baseline.json`（如存在）与文档。
- **不在范围内**：第二批（SurveyEditor / ReportEditor / ConsultCollections）与第三批文件；功能改动；样式重设计。
- **风险**：中：迁移顺序或路由注册顺序出错会影响启动/接口；拆分时只移动代码，不改逻辑。
