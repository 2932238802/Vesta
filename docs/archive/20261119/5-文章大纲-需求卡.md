## CR-013 文章大纲（TOC）

- **类型**：阅读体验优化
- **问题与价值**：导入的长文（如「地域产业与家长心智」16 个小节、6500 字）只能从头往下滚，通话中找不到某一地区或某一段。需要从 Markdown 标题自动生成提纲，点击跳转。
- **目标用户与场景**：咨询师；打开长文后从右侧大纲直接跳到“长三角”“大湾区”“河南”等小节。
- **成功指标**：
  - 打开带标题的文章，右侧出现与正文一致的提纲。
  - 点击提纲条目，正文滚动到对应小节；滚动时当前小节高亮。
  - 窄屏通过“目录”按钮打开大纲，不挤压正文。
- **验收标准**：

  - `AC-013-1` 阅读视图从 Markdown 的 `##` / `###` 自动生成提纲；层级与正文一致（`###` 作为条目；若存在 `##` 则作为分组）。
  - `AC-013-2` 点击提纲条目平滑滚动到对应标题；滚动正文时当前小节高亮。
  - `AC-013-3` 桌面（>1000px）提纲固定在正文右侧，随页面滚动保持可见；正文宽度不被压缩到不可读。
  - `AC-013-4` ≤1000px：显示“目录”按钮，点开为抽屉/浮层，选择条目后关闭并跳转；390px 无横向溢出。
  - `AC-013-5` 文章没有标题时（或只有正文段落）不显示空提纲。
  - `AC-013-6` 标题锚点稳定：刷新、深链后仍可定位；不破坏现有 Markdown 渲染（加粗、列表、链接）。
  - `AC-013-7` 其他页面（金句栏、故事集、有效的提问、咨询树、知识库、收藏栏直达）不受影响。
  - `AC-013-8` `npm run verify` 全绿；本期不升版本（保持 1.99.0）。
- **范围**：`web/src/views/admin/basics/TopicView.vue`、新增提纲组件、`consultBasics.css`。仅阅读视图，不改数据与接口。
- **不在范围内**：专业知识汇总的阅读页（后续复用同一组件）、编辑弹窗预览、折叠章节内容。
- **风险**：滚动高亮与固定定位在窄屏下需要单独处理；标题重复时需要生成唯一锚点。
