## CR-011 金句栏类别双击改名与拖拽排序

- **类型**：交互优化
- **问题与价值**：金句栏的分类改名和调序现在要打开“管理分类”弹窗，再点改名或上下移，操作链路长。咨询师在通话前整理金句时，希望能直接在左侧分类栏双击改名、按住拖动调序。
- **目标用户与场景**：咨询师；整理金句时直接在分类栏完成改名和排序，不离开当前页面。
- **成功指标**：
  - 双击分类名后直接进入编辑，Enter 保存，操作 ≤ 2 步。
  - 拖动分类后顺序立即变化，刷新后保持。
  - 原有的“管理分类”弹窗仍可用。
- **验收标准**：

  - `AC-011-1` 双击任意分类名（不含“全部金句”“置顶”）进入行内编辑：输入框出现并自动聚焦、选中原名；单击分类仍是筛选，不会误触发改名。
  - `AC-011-2` 行内编辑按 Enter 或失焦保存；按 Esc 取消并恢复原名；保存成功后分类栏与卡片上的分类名同步。
  - `AC-011-3` 行内改名成空或与已有分类重名时，保存被拒绝并给出可读错误，名称恢复原值，不产生脏数据。
  - `AC-011-4` 鼠标按住分类可拖动排序，拖动时有视觉反馈；松手后顺序立即变化并通过现有排序接口持久化，刷新后保持。
  - `AC-011-5` “全部金句”“置顶”为固定项，不可拖动、不可双击改名；拖动分类不会改变当前选中的分类。
  - `AC-011-6` 排序保存失败时恢复拖动前顺序并提示错误，不出现只改了一半的状态。
  - `AC-011-7` 原有“管理分类”弹窗的新增、改名、上移/下移、删除限制、重名 409 全部保持可用。
  - `AC-011-8` 390px 下分类栏不横向溢出；行内编辑与拖动在鼠标环境下可用（触屏拖拽不保证，沿用 A-037 口径）。
  - `AC-011-9` `npm run verify` 全绿；版本 `1.99.0` 与 README、development-history、04、09 一致。

- **NFR**：性能/安全/隐私/成本不适用（复用现有接口，无新增表）；兼容性适用（不改接口与数据）；可观测性不适用（沿用现有日志）。
- **范围**：
  - `web/src/views/admin/ConsultQuotes.vue`（分类栏模板与交互）
  - `web/src/views/admin/quotes/useQuoteShelf.ts`（改名、排序动作与回滚）
  - `web/src/views/admin/consultQuotes.css`（编辑态与拖动态样式）
  - 版本与文档
- **不在范围内**：接口/数据模型改动；新增分类方式；弹窗下线；触屏拖拽；键盘升降序按钮。
- **风险**：双击与单击、拖动与点击的判定需要阈值；行内编辑与拖动同时触发要互斥。
