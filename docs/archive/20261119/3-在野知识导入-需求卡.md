## CR-012 知识库导入试点（大学常识）

- **类型**：内容导入（试点）
- **问题与价值**：咨询沉淀文档有 9.4 万字，需要先验证“源内容 → 大学常识话题”的转换质量与呈现效果，再决定其余篇目如何切分。
- **目标用户与场景**：咨询师在通话中打开「大学常识 → 地域产业与家长心智」，按学员所在地区快速判断家庭心智与切入方式。
- **成功指标**：
  - 大学常识左侧出现 1 个新话题，右侧 Markdown 正文完整、可读。
  - 同一脚本重复执行不产生重复话题。
  - 其余篇目尚未导入，页面其他内容不受影响。
- **验收标准**：

  - `AC-012-1` 大学常识左侧新增「地域产业与家长心智」，点击后右侧显示面包屑、标题与完整正文。
  - `AC-012-2` 正文保留原文的章节层级（地域如何决定选择 / 产业丰富度与体制内执念 / 各区域小节），标题、列表、加粗正常渲染；`####` 统一降为 `###`，去掉“一、七、九、”等序号前缀。
  - `AC-012-3` 内容为原文清洗，不新增观点、不删减区域；表格与括号备注保留。
  - `AC-012-4` 导入脚本默认 dry-run，只打印将写入的话题；`--write` 才落库；重复执行按稳定 id 跳过，不覆盖已有人工修改。
  - `AC-012-5` 不修改其他表与页面；金句栏、故事集、有效的提问、咨询树、知识库组不受影响。
  - `AC-012-6` `npm run verify` 全绿。
- **范围**：
  - 新增 `scripts/import-consult-topics.ts`（可扩展到其他内容类型）与内容包 `server/src/data/consult-topics-import.json`。
  - 本期只导入 1 个话题；其余篇目待试点确认后再做。
- **不在范围内**：01/02/03/06 的导入；专业就业地图；金句/故事/提问；图片；版本号升级（等内容齐了随 v2.0 处理）。
- **风险**：原文含口语化与括号备注，需保留但排版要清晰；内容时效需维护者核对。
