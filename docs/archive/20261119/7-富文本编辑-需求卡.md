## CR-014 大学常识编辑体验

- **类型**：交互优化
- **问题与价值**：Markdown 文本框对咨询师不友好；阅读页顶部“更新于 … · 管理员维护”对使用者没有价值。需要像 Word 一样直接改正文，并去掉多余元信息。
- **目标用户与场景**：咨询师维护大学常识时，直接在格式化正文里改标题、加粗、列表，不需要懂 Markdown。
- **成功指标**：
  - 编辑弹窗打开后看到的是已排版正文，而不是 Markdown 源码。
  - 工具栏可完成标题、加粗、斜体、列表、引用、链接；保存后阅读页与编辑态一致。
  - 阅读页不再显示“更新于 / 管理员维护”。
- **验收标准**：

  - `AC-014-1` 阅读视图（大学常识）不再显示“更新于 …”与“管理员维护”；面包屑、标题、正文保留。
  - `AC-014-2` 编辑弹窗以所见即所得方式呈现正文：已有 Markdown 标题、加粗、列表、引用、链接直接显示为排版结果。
  - `AC-014-3` 工具栏支持：正文、二级标题、三级标题、加粗、斜体、无序列表、有序列表、引用、链接；操作即时生效。
  - `AC-014-4` 保存后仍存为 Markdown；阅读页渲染与编辑态一致；重新打开编辑弹窗保持一致。
  - `AC-014-5` 正文为空（仅空白）时保存被拒绝并提示；标题必填规则不变。
  - `AC-014-6` 粘贴为纯文本，不引入外部 HTML / 样式；不支持的能力（表格、图片）不破坏现有内容。
  - `AC-014-7` 390px 下工具栏可横向滚动、正文编辑区不横向溢出。
  - `AC-014-8` 其他页面（金句栏、故事集、有效的提问、咨询树）不受影响；`npm run verify` 全绿；本期不升版本。
  - `AC-014-9` 同一编辑器复用到「专业知识汇总」的知识点编辑与「收藏栏」条目编辑（直达页）：打开即排版视图，保存仍为 Markdown，阅读端一致。
- **范围**：
  - `web/src/views/admin/basics/TopicEditorModal.vue`、`knowledge/ArticleEditorModal.vue`、`ConsultCollections.vue` / `ConsultCollectionDetail.vue`（换成富文本编辑器）
  - 新增 `web/src/views/admin/components/RichTextEditor.vue` 与 HTML→Markdown 转换工具
  - `web/src/views/admin/basics/TopicView.vue`（移除元信息行）
  - `consultBasics.css`
- **不在范围内**：图片粘贴上传；表格编辑；协同编辑；写咨询稿的结构化编辑器。
- **风险**：HTML→Markdown 转换需覆盖现有格式；粘贴清洗；撤销依赖浏览器原生。
