## 3. 关键设计

### 3.1 编辑器

- 新增 `web/src/views/admin/components/RichTextEditor.vue`：
  - props：`modelValue`（Markdown）、`disabled`；
  - 内部：用 `renderMarkdown(modelValue)` 生成初始 HTML，写入 `contenteditable` 容器；
  - 输入时（`input` 事件）把容器 HTML 转成 Markdown，`update:modelValue`；
  - 工具栏：正文 / 二级标题 / 三级标题 / 加粗 / 斜体 / 无序列表 / 有序列表 / 引用 / 链接；
  - 使用 `document.execCommand`（标题用 `formatBlock`，列表用 `insertUnorderedList` / `insertOrderedList`，链接用 `createLink` 并校验 http/https）；
  - 粘贴：`paste` 事件拦截，读取 `text/plain` 后 `insertText`，不保留外部样式与 HTML。
- 转换工具 `web/src/views/admin/components/htmlToMarkdown.ts`：
  - 支持 `h2/h3/p/strong/b/em/i/ul/ol/li/blockquote/a/br`；
  - 其他标签降级为文本；
  - 链接只保留 http/https；输出稳定 Markdown。
- 工具栏按钮使用 `mousedown.prevent`，避免编辑器失焦。

### 3.2 弹窗

- `TopicEditorModal.vue`、`knowledge/ArticleEditorModal.vue`、`ConsultCollections.vue` / `ConsultCollectionDetail.vue` 用 `RichTextEditor` 替换 textarea 与“编辑/预览”切换；
- 保存前检查 Markdown 去空白后非空，否则提示“正文不能为空”；
- 其他字段（标题）与校验不变。

### 3.3 阅读页

- `TopicView.vue` 删除 `.article-meta`（更新于 / 管理员维护）；
- 面包屑、标题、正文、编辑/删除按钮保留。

### 3.4 边界

- 转换不支持表格/图片：若现有内容含这些语法，编辑器初始化时按现有渲染器显示，保存时不主动删除未修改的内容（转换器对未知块保留纯文本）。
- 390px：工具栏 `overflow-x: auto`，编辑区 `min-width: 0`。
