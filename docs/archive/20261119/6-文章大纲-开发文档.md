## 3. 关键设计

### 3.1 数据来源

- 正文由 `renderMarkdown(topic.body)` 注入 `v-html`。
- 渲染完成后在 DOM 中查询正文容器内的 `h2, h3`：
  - 生成 `{ level, text, id }` 列表；
  - 为每个标题设置稳定 `id`：优先用文本生成 slug，重复时追加序号（如 `-2`）。
- 正文切换（`topic.id` 变化）时重建提纲。

### 3.2 组件

- 新增 `web/src/views/admin/basics/MarkdownOutline.vue`：
  - props：`headings`、`activeId`；
  - emit：`select(id)`；
  - 渲染分组（`h2` 为组，`h3` 为条目）；没有 `h2` 时平铺。
- `TopicView.vue` 负责：
  - 读取标题、生成锚点；
  - `IntersectionObserver` 或滚动监听计算当前小节；
  - 点击 `scrollIntoView({ behavior: 'smooth', block: 'start' })`；
  - ≤1000px 时用 `outlineOpen` 控制浮层。

### 3.3 布局与样式

- 桌面：正文容器改为两列（`minmax(0,1fr) 220px`），大纲 `position: sticky; top: 20px`；正文最大宽度仍 760px。
- 提纲条目单行省略，当前项左侧竖线与强调色。
- ≤1000px：隐藏右侧栏，显示“目录”按钮；浮层覆盖在正文上方，点条目后关闭。
- 390px：浮层宽度 `calc(100vw - 32px)`，不产生横向滚动。

### 3.4 边界

- 无标题：不渲染大纲，也不留空列。
- 标题文本重复：锚点加序号，保证唯一。
- 标题变化（编辑后保存）：重建大纲并清除旧观察器。
