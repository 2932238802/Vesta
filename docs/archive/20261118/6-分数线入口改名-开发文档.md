## 1. 需求 R-003 分数线入口改名（P2，v1）

- **来源**：CR-003（2026-11-18，G0 用户选择方案 A）。
- **背景**：后台侧栏的“分数线”只说明了数据是什么，没有说明这是给人查升学分数线的入口。运营和咨询师需要按名称就能判断入口用途。
- **描述**：把后台“分数线”栏目的入口名称改为“升学分数线查询”。侧栏一级分组标题保留“分数线”；页面大标题与浏览器标签标题同步改名。路由、接口、数据、权限、页面功能保持不变。
- **成功指标**：
  - 侧栏“分数线”分组下显示“升学分数线查询”，点击进入原有分数线页面。
  - 页面大标题与浏览器标签标题与入口名称一致。
  - 旧链接 `/admin/score-lines` 仍可直接访问，页面功能与改名之前完全一致。
- **验收标准**：

  - `AC-003-1` 后台任意页面侧栏中，“分数线”分组下唯一入口显示为“升学分数线查询”；点击后进入 `/admin/score-lines`，入口高亮，分组保持展开。
  - `AC-003-2` 分数线页面大标题为“升学分数线查询”；`eyebrow`（“内部查询”）与副标题文案保持不变。
  - `AC-003-3` 浏览器标签标题为“升学分数线查询 · 管理后台”；切换到其他后台页面后标题正确切换，不残留旧名。
  - `AC-003-4` 直接访问 `/admin/score-lines`：页面正常渲染，筛选、抓取队列、复核、覆盖看板、人工导入等入口与改名之前一致；接口与数据无变化。
  - `AC-003-5` 其余导航入口文案与本轮之前完全一致（尤其“咨询”组仍为 写咨询稿 → 咨询树 → 金句栏 → 收藏栏；侧栏一级分组仍显示“分数线”）。
  - `AC-003-6` 390px 窄屏下侧栏标签条不出现换行错位、溢出或遮挡；新文案完整显示。
  - `AC-003-7` `npm run verify` 全绿（含 `check:docs` / `check:size` / `check:version`），版本号与文档版本一致。

- **NFR 影响**：

| 项 | 判定 | 目标 / 理由 |
| --- | --- | --- |
| 性能 | 不适用 | 纯前端文案，无请求变化。 |
| 安全 | 不适用 | 无接口、鉴权、渲染方式变更。 |
| 隐私与数据保留 | 不适用 | 无数据处理。 |
| 兼容性 | 适用 | 只改显示文案；路由路径、接口、书签、外部链接全部不变。 |
| 可观测性 | 不适用 | 无新增日志。 |
| 成本 | 不适用 | 无新增依赖。 |

- **影响面**：
  - 前端：`web/src/views/admin/AdminLayout.vue`（仅入口链接文本）、`web/src/views/admin/ScoreLines.vue`（页面标题）、`web/src/router.ts`（路由标题表）。
  - 后端：无。
  - 数据：无。
  - 测试：无自动化 UI 测试；以 `npm run verify` + 页面手工走查为准。
- **不在范围内**：分组标题改名（保留“分数线”）；页面副标题与 `eyebrow` 改写；正文里“分数线”作为数据名词的表述；路由路径调整；导航结构重排；其他栏目改名。
- **变更历史**：v1 2026-11-18 初始（CR-003，G0 选 A）。

### 3.1 改动点

| # | 文件 | 位置 | 改前 | 改后 |

- 侧栏：登录后台 → 任意页面确认“分数线”分组下入口文案；点击后 URL 为 `/admin/score-lines` 且入口高亮。

- 窄屏：390px 宽度下侧栏标签条完整显示新文案，无溢出与错行。
- 回归：分数线页面的抓取队列、复核、覆盖看板、人工导入按钮可用；咨询组四个入口文案与顺序不变。
