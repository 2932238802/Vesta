## CR-010 大学常识

- **类型**：新功能
- **问题与价值**：咨询中经常遇到“入党流程”“奖助学金怎么评”“转专业怎么操作”这类大学常识问题，咨询师需要快速查到一份可靠说明。现在这些信息散落在聊天记录和学校文件里，临时找不全，也容易记错。
- **目标用户与场景**：咨询师；通话中按话题打开“大学常识”，右侧立即看到一篇说明，照着讲或直接引用。
- **成功指标**：
  - 从进入页面到打开一个话题 ≤ 2 次操作（点话题）。
  - 新建 / 编辑话题后刷新仍在，列表计数一致。
  - 可观察场景：打开“入党的流程”，右侧显示五个阶段的 Markdown 正文；拖动调整两个话题顺序后刷新，顺序保持。
- **验收标准**：

  - `AC-010-1` 侧栏“咨询”组顺序为 写咨询稿 → 金句栏 → 故事集 → 有效的提问 → **大学常识** → 咨询树；点击进入 `/admin/consult/basics`，页面标题“大学常识”，分组高亮。
  - `AC-010-2` 左侧话题栏显示全部话题与数量；输入关键字按标题过滤并显示结果数；无匹配显示空状态；清空恢复。
  - `AC-010-3` 点击话题：右侧显示面包屑「大学常识 / 标题」、标题、更新时间与正文；默认打开第一个话题；直接访问 `/admin/consult/basics/:id` 可打开同一篇。
  - `AC-010-4` 正文按 Markdown 渲染（标题、加粗、列表、链接、代码）；原始 HTML / `<script>` 以文本显示、不执行；`javascript:` 链接不可点击。
  - `AC-010-5` 新建话题：标题与正文必填；保存后出现在列表末尾并自动选中，计数 +1；编辑标题/正文后立即反映；删除二次确认后移除、计数 -1。
  - `AC-010-6` 鼠标按住话题可拖动排序，拖动时有视觉反馈；松手后顺序立即生效并持久化，刷新后保持；默认顺序为创建时间（新话题追加在末尾），未手动排序时不会被随机打乱。
  - `AC-010-7` 搜索过滤状态下禁用拖动（或拖动仅作用于当前结果并给出提示），避免顺序歧义。
  - `AC-010-8` 390px：话题栏全宽；点击话题切换到阅读视图，左上角“返回话题列表”可用；阅读页无横向溢出。
  - `AC-010-9` 与金句栏、故事集、有效的提问、咨询树、知识库组互不影响。
  - `AC-010-10` 异常与鉴权：未登录 401；标题为空 / 超长、正文为空 / 超长返回 400；不存在话题 404；排序 ids 非法 400；页面失败显示错误与重试。

- **字段建议**：标题（必填）、正文 Markdown（必填）、`sort_order`、创建/更新时间。
- **能力**：话题增删改；拖拽排序（持久化）；搜索；Wiki 阅读；深链；移动端返回。
- **非目标**：分类/分组；AI 生成；导入；版本历史；多人协作；全文检索；话题内目录（TOC）。
- **风险**：
  - 拖拽与页面滚动可能冲突，需 pointer 事件与触摸兜底。
  - Markdown 是新的注入面，必须复用已验证渲染器并测 XSS。
  - 内容可能引用真实政策，需要维护者自行核对时效。
