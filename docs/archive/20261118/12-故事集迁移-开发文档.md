## 1. 需求 R-007 故事集迁移（P2，v1）

- **来源**：CR-007（2026-11-18，G0 确认组内位置 A）。
- **背景**：故事集与金句栏、专业知识汇总同属“通话中查资料”，现在留在咨询组，咨询师需要在两个分组间切换。
- **描述**：把“故事集”从咨询组移到「知识库 & 数据库」组，位置在“金句栏”与“专业知识汇总”之间。路由、页面、接口、数据、功能全部不变；“咨询”组只保留写咨询稿与咨询树。
- **成功指标**：
  - 知识库组四个入口顺序为 升学分数线查询 → 金句栏 → 故事集 → 专业知识汇总。
  - 咨询组只剩写咨询稿、咨询树。
  - 故事集页面与操作与迁移前完全一致。
- **验收标准**：

  - `AC-007-1` 侧栏分组顺序为 问卷 → 咨询 → 知识库 & 数据库 → 设置；咨询组为 写咨询稿 → 咨询树；知识库组为 升学分数线查询 → 金句栏 → 故事集 → 专业知识汇总；点击故事集进入 `/admin/consult/stories`。
  - `AC-007-2` 故事集页面标题“故事集”、浏览器标题“故事集 · 管理后台”、分类与故事数据、搜索、复制、置顶、增删改、分类管理、全文弹窗全部与迁移前一致。
  - `AC-007-3` 在故事集页面时“知识库 & 数据库”分组高亮且展开；切到学员名单/写咨询稿后高亮正确切换。
  - `AC-007-4` 其余页面不受影响：分数线、金句栏、专业知识汇总、收藏栏直达、写咨询稿、咨询树。
  - `AC-007-5` 390px 下知识库组四个入口完整显示，无横向溢出、无遮挡、无重叠。
  - `AC-007-6` `npm run verify` 全绿；版本 `1.95.0` 与 README、development-history、04、09 一致。

- **NFR 影响**：

| 项 | 判定 | 目标 / 理由 |
| --- | --- | --- |
| 性能 | 不适用 | 纯导航位置调整。 |
| 安全 | 不适用 | 无接口、鉴权、渲染变化。 |
| 隐私与数据保留 | 不适用 | 无数据处理。 |
| 兼容性 | 适用 | 路由 `/admin/consult/stories` 不变，旧链接与书签可用。 |
| 可观测性 | 不适用 | 无新增日志。 |
| 成本 | 不适用 | 无新增依赖。 |

- **影响面**：
  - 前端：`web/src/views/admin/AdminLayout.vue`（入口位置与 `activeGroup`）。
  - 后端 / 数据：无。
  - 测试：`npm run verify` + 手工走查 + Playwright。
- **不在范围内**：故事集功能改造；咨询组其他入口；收藏栏恢复；导航配置化或拖拽。
- **变更历史**：v1 2026-11-18 初始（CR-007，G0 确认位置 A）。
