## CR-008 有效的提问（咨询 › 有效的提问）

- **类型**：新功能
- **问题与价值**：咨询师在通话里需要用好问题把话题打开、把学生真实想法问出来，但这些问法散落在个人笔记里，临时想不起来；而且同一个问题对不同学生的效果不同，需要一条只有咨询师能看到的备注记录“什么时候用、怎么问”。
- **目标用户与场景**：咨询师；通话中按主题（开场、目标、动力、家庭、就业…）打开对应分类，找到一个问题，直接照着问；看完备注知道这个问题的适用场景与追问方式。
- **成功指标**：
  - 从进入页面到复制一个问题 ≤ 3 次操作（选分类 → 找条目 → 复制）。
  - 给一个问题加备注后刷新仍在，且不影响原有提问内容与复制结果。
  - 可观察场景：新建“开场”分类，添加“你最近一次觉得时间过得特别快是什么时候？”，加备注“适合冷场时用，追问细节”；复制得到问题原文，不含备注。
- **验收标准**：

  - `AC-008-1` 侧栏“咨询”组新增“有效的提问”，位于咨询树之后；点击进入 `/admin/consult/questions`，页面标题“有效的提问”。
  - `AC-008-2` 分类栏显示“全部提问”“置顶”和全部已有分类，计数正确；切换分类列表只显示该类；无分类时引导先建分类。
  - `AC-008-3` 搜索覆盖提问正文、备注与分类名；结果显示条数；无结果空状态；清空恢复。
  - `AC-008-4` 复制只复制提问正文，不含备注、分类；按钮短暂显示“已复制”；连续复制正确。
  - `AC-008-5` 置顶：★ 与排序、计数、“置顶”筛选、刷新保持、取消置顶回原序。
  - `AC-008-6` 新增 / 编辑 / 删除提问：正文、分类、备注、置顶可编辑；正文为空被拒绝；删除二次确认；计数同步。
  - `AC-008-7` 备注：每道题一条备注，可为空；在卡片上展示（折叠或小字）；只有咨询师在后台可见；编辑备注后立即更新且刷新保持。
  - `AC-008-8` 分类管理：新增、改名、上下调序、非空不可删（409 并提示条数）、空分类可删、重名/空名被拒绝。
  - `AC-008-9` 与金句栏、故事集、专业知识汇总、收藏栏互不影响；接口与数据独立。
  - `AC-008-10` 异常与鉴权：未登录 401；分类不存在 / 正文或备注超长 400；不存在 404；页面失败有错误与重试。

- **建议字段**：分类、提问正文（必填）、备注（选填，咨询师填写）、置顶。
- **建议能力**：分类增删改调序；提问增删改、复制、置顶、搜索；备注编辑与展示。
- **非目标**：AI 生成提问；导入；使用统计；多备注历史 / 多人协作；把备注带进复制内容；接入咨询稿生成。
- **风险**：
  - 备注可能含学员隐私，表单提示脱敏；日志不记录正文与备注。
  - 与金句栏结构相似，存在两套相似实现；本次不抽取通用组件。
