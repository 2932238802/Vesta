# 金句栏：咨询栏目下独立的金句收藏与通话速查

> 维护者：Doc Agent ｜ 最近更新：2026-11-18 ｜ 状态：已确认（G0）
> 关联文档：`docs/archive/20261118/4-金句栏-开发文档.md`（R-002 / AC / T）

## CR-002 金句栏（咨询 › 金句栏）

- **类型**：新功能
- **问题与价值**：咨询师在通话中需要按主题快速找两三句有分量的话。现有“收藏栏”把金句、完整咨询稿、公众号链接混在一起，且按“收藏类型”筛选，没有主题维度；136 组金句导入后也只能混在卡片流里翻。做一个按主题组织的独立金句栏，能把“通话中翻找”的动作压缩到几秒。
- **目标用户与场景**：咨询师；通话进行中，根据学生当下的话题（拖延、内耗、就业、家庭…）打开对应分类，挑两三条直接复制到对话里。
- **成功指标**：
  - 咨询师从进入金句栏到复制一条金句，不超过 3 次操作（选分类 → 找条目 → 复制）。
  - 首屏 140 条金句在本地完成加载与筛选，切换分类无额外请求等待。
  - 分类名、条数与 Word 原稿一致：11 个分类、140 条（136 个主编号 + 4 条字母补充编号）。
  - 无法量化部分用可观察场景代替：通话中打开“自卑、内耗与在意评价”，能看到 14 条，点“随机三条”得到 3 条并一次复制成功。
- **范围**：
  - 咨询导航新增“金句栏”，位于“咨询树”和“收藏栏”之间，独立页面。
  - 独立数据表与接口：金句、分类分开存储。
  - 金句：新增、编辑、删除、置顶、复制、按分类筛选、搜索、随机三条。
  - 分类：新增、改名、上下调序；分类下仍有金句时不可删除。
  - 首批 11 类 140 条通过服务启动迁移写入一次；之后全部人工维护。
- **非目标**：
  - 不做 Word 导入（本次明确移除该入口，避免与人工维护冲突）。
  - 不改“收藏栏”的页面、数据与接口；收藏栏暂时保留，后续可能单独下线。
  - 不做 AI 推荐、自动打标签、金句使用次数统计。
  - 不把金句接入咨询稿生成流程。
  - 不做金句拖拽排序、批量导入/导出。
- **NFR**：
  - 性能：适用。单页一次性读取全部分类与金句（当前量级 140 条），筛选在浏览器完成；目标是在普通笔记本上切换分类无可感知延迟。
  - 安全：适用。所有接口沿用管理员登录态与 `requireAdmin()`；金句正文按纯文本渲染，不解析 Markdown/HTML；服务端校验长度与归属。
  - 隐私与数据保留：适用。种子数据来自公开整理的咨询金句，不含学员个人信息；日志只记录 id 与分类，不记录正文；删除金句为硬删除，需二次确认。
  - 兼容性：适用。纯新增表、接口、路由，不修改现有接口；收藏栏数据与页面保持不变。
  - 可观测性：适用。新增/编辑/删除/分类变更写结构化日志（`consult.quote_*` / `consult.quote_category_*`），失败带 `reqId`；不记录正文。
  - 成本：不适用。不新增外部调用或基础设施。
- **约束与依赖**：
  - 数据写入必须走 `server/src/db/migrations.ts` 的幂等迁移，不新增一次性脚本、不改 `update.sh`（`docs/reference/06-数据模型.md` §4 已明确该规则）。
  - 新文件不超过 400 行；`ConsultCollections.vue` 已 1044 行，本次不向其中加功能。
- **风险与未知**：
  - 首次启动迁移失败会导致金句缺失（服务本身仍可启动）；迁移不写标记，下一次 `update.sh` 重启后重试。
  - 分类改名/调序是即时生效；误操作没有撤销，需要靠二次确认与清晰文案控制。
  - Word 原稿开头写“136 条”，实际为 140 条（含 124b/124c/98b/103b 四条补充编号）；种子以实际 140 条为准。
- **选项**：
  - A. 做（本次已选）：独立页面 + 独立表 + 启动种子，范围如上。
  - B. 拆小：先只做“按分类浏览 + 复制”，编辑与分类管理后置。
  - C. 先 spike：只验证 Word 解析与数据分布，不建页面。
  - D. 缓办：继续用收藏栏的“金句”类型筛选。
  - E. 不做：维持现状。
- **推荐（用户已选）**：A。理由：分类和 140 条数据已经就绪，延后没有收益；独立页面能直接解决通话中的检索问题，且与收藏栏解耦后，后续下线收藏栏不影响金句。
- **关联需求/任务**：R-002（v1） / T-006 ~ T-012，见开发文档。
- **状态**：已确认（2026-11-18，用户确认“就 docs，按这个做”）。
