## 1. 需求 R-005 故事集（P1，v1）

- **来源**：CR-005（2026-11-18，G0 已确认）。
- **背景**：咨询师在通话里需要用具体故事回应学生，内容散落在聊天记录与个人笔记里，调用成本高。金句栏解决“短句”，故事需要独立空间承载“有长度、有情节、可按主题找”的内容。
- **描述**：后台“咨询”组新增“故事集”页面，位于“金句栏”与“收藏栏”之间。左侧为分类栏，右侧为故事列表；支持按分类筛选、关键字搜索、单条复制、置顶、新增、编辑、删除；支持分类新增、改名、上下调序，分类下仍有故事时不可删除。首期为空页面，全部内容人工维护。
- **成功指标**：
  - 进入故事集到复制一篇故事 ≤ 3 次操作（选分类 → 找条目 → 复制）。
  - 新增一篇故事后列表立即可见，刷新后仍在。
  - 可观察场景：新建“家庭沟通”分类，添加一篇带标题的故事；切到该分类能看到；复制后剪贴板与正文逐字一致；刷新后数据仍在。
- **验收标准**：

  - `AC-005-1` 打开 `/admin/consult/stories`：侧栏“咨询”组顺序为 写咨询稿 → 咨询树 → 金句栏 → 故事集 → 收藏栏；故事集高亮；页面标题“故事集”；金句栏与收藏栏入口仍在且可进入。
  - `AC-005-2` 分类栏显示“全部故事”“置顶”和全部已有分类；每个分类右侧条数等于该分类故事数；点击分类后列表只显示该类故事并高亮；切回“全部故事”恢复全部；无分类时显示引导文案且不报错。
  - `AC-005-3` 搜索框输入标题、正文中的词或分类名：列表即时过滤并显示结果条数；清空搜索恢复当前分类全部条目；无结果显示空状态。
  - `AC-005-4` 点击故事卡片“复制”：剪贴板内容与正文完全一致（不含标题、分类、出处）；按钮短暂显示“已复制”；连续复制不同条目均正确；正文折叠时复制仍是全文。
  - `AC-005-5` 点击“☆”置顶：变为“★”并移动到列表顶部；“置顶”分类只显示置顶条目且计数正确；再次点击取消置顶，条目回到原顺序。
  - `AC-005-6` 新增故事：选择分类、填写标题与正文后保存，新条目出现在对应分类末尾，总数 +1，计数同步；标题或正文为空时保存被拒绝并提示。编辑：修改标题、正文、分类、出处、置顶后保存，列表立即反映。删除：二次确认后从列表与数据库移除，总数 -1。
  - `AC-005-7` 分类管理：新增分类出现在分类栏末尾；改名后分类栏与卡片上的分类名同步；上移/下移后顺序立即变化且刷新后保持；分类下仍有故事时“删除”不可用或返回 409 并提示；空分类可删除；分类名为空或重复时被拒绝。
  - `AC-005-8` 长正文：卡片默认折叠 4 行，点“查看全文”打开详情弹窗，弹窗内显示完整正文并可滚动；按 Esc 或点遮罩 / 关闭按钮可关闭并回到列表；正文接近上限（20000 字）时弹窗打开不卡死、不横向溢出。
  - `AC-005-9` 与金句栏、收藏栏互不影响：金句栏 11 类 140 条数据、页面与接口保持原样；故事不会出现在金句栏或收藏栏，收藏栏与金句栏的数据也不会进入故事集。

## 3. 关键设计

### 3.1 信息架构

- 路由：`/admin/consult/stories`，名称 `admin-consult-stories`，页面标题 `故事集 · 管理后台`。
- 导航顺序：写咨询稿 → 咨询树 → 金句栏 → **故事集** → 收藏栏（`AdminLayout.vue` 咨询组内，插在 `consult/quotes` 之后）。
- 布局沿用金句栏：左分类栏（全部故事 / 置顶 / 各分类 / 管理分类）+ 右侧搜索与故事列表；≤1000px 时分类栏收为横向标签条。
- 故事卡片：标题（单行省略，完整标题在 `title` 属性）+ 分类名 + 出处（有则显示）+ 正文折叠 4 行 + “查看全文” + 复制按钮；悬停显示置顶、编辑、删除。
- 顶部动作：新增故事（**不放“随机”**，A-010 已确认不要）。
- 复制内容：**仅正文**（A-011 已确认）；长正文折叠或弹窗中复制，内容都是全文。
- 全文查看：**弹窗查看**（A-012 已确认）：卡片折叠 4 行，点“查看全文”打开弹窗；弹窗显示标题、分类、出处与完整正文，正文区域可滚动；支持 Esc、遮罩与关闭按钮关闭，不做独立详情路由。

### 3.2 数据模型

```sql
CREATE TABLE IF NOT EXISTS consult_story_categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_consult_story_categories_name
  ON consult_story_categories(name);
CREATE INDEX IF NOT EXISTS idx_consult_story_categories_order
  ON consult_story_categories(sort_order, id);

CREATE TABLE IF NOT EXISTS consult_stories (
  id TEXT PRIMARY KEY,
  category_id TEXT NOT NULL,
  title TEXT NOT NULL,
  text TEXT NOT NULL,
  source TEXT NOT NULL DEFAULT '',
  pinned INTEGER NOT NULL DEFAULT 0,
  pinned_at TEXT NOT NULL DEFAULT '',
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_consult_stories_category
  ON consult_stories(category_id, pinned DESC, pinned_at DESC, sort_order, created_at);
```

- 不启用数据库外键；分类存在性、删除限制在接口层校验（与金句栏一致）。
- `sort_order` 只在同一分类内保证稳定顺序；本次不提供手工排序，新增 / 移入分类排在该分类末尾。
- `pinned_at` 记录最近一次置顶的时间（ISO 字符串）；未置顶为空字符串。置顶时写入当前时间，取消置顶清空；已置顶条目在编辑其他字段时保持原时间。

### 3.3 接口契约

统一前缀 `/api/admin/consult`，沿用管理员登录态。

| 方法 | 路径 | 作用 | 成功响应 |
| --- | --- | --- | --- |
| `GET` | `/stories` | 读取全部分类与故事 | `{ categories, stories }` |
| `POST` | `/stories` | 新增故事 | `{ item }` |
| `PATCH` | `/stories/:id` | 编辑标题 / 正文 / 分类 / 出处 / 置顶 | `{ item }` |
| `DELETE` | `/stories/:id` | 删除故事 | `{ ok: true }` |
| `POST` | `/story-categories` | 新增分类 | `{ category }` |
| `PATCH` | `/story-categories/:id` | 分类改名 | `{ category }` |
| `PUT` | `/story-categories/order` | 全量重排 | `{ categories }` |
| `DELETE` | `/story-categories/:id` | 删除空分类 | `{ ok: true }` |

响应对象：

```ts
interface ConsultStoryCategory { id: string; name: string; sortOrder: number; count: number }
interface ConsultStory {
  id: string; categoryId: string; title: string; text: string;
  source: string; pinned: boolean; pinnedAt: string; sortOrder: number;
  createdAt: string; updatedAt: string
}
```

校验与错误：

- 标题 `trim` 后 1–120 字；正文 `trim` 后 1–20000 字；出处 ≤200 字；否则 `400`。
- 分类名 `trim` 后 1–30 字；重名 `409`；改名同样校验。
- `categoryId` 必须存在，否则 `400`。
- `PUT /story-categories/order` 的 `ids` 必须恰好是现有全部分类的一个排列，否则 `400`；单事务写入。
- 删除非空分类 `409`，响应含该分类故事数；不存在 `404`；未登录 `401`。
- 日志只记录 `id` / `categoryId` / `pinned` / `count`，不记录标题与正文。

- 本次提取到 `web/src/clipboard.ts`，`QuoteCard.vue` 与 `ConsultQuotes.vue` 两处 import 指向新路径，删除旧文件；不改变任何复制行为。

### 3.5 前端结构

为满足“新文件 ≤400 行”：

- `web/src/views/admin/ConsultStories.vue`：页面骨架、数据加载、搜索与筛选状态。
- `web/src/views/admin/stories/StoryCard.vue`：标题、正文折叠、“查看全文”、复制、置顶、编辑/删除入口。
- `web/src/views/admin/stories/StoryDetailModal.vue`：全文弹窗（标题、分类、出处、完整正文、复制）。
- `web/src/views/admin/stories/StoryFormModal.vue`：新增/编辑表单（标题、分类、正文、出处、置顶）。
- `web/src/views/admin/stories/StoryCategoryModal.vue`：分类管理（新增、改名、上下移、删除限制）。
- `web/src/views/admin/stories/useStoryShelf.ts`：接口调用、本地状态、排序与计数派生。
- 共享类型 `shared/src/consult-story.ts`；请求方法加入 `web/src/api/consult.ts`，类型加入 `web/src/api/types.ts`。

交互口径：

- 列表排序：置顶优先；置顶组内按 `pinnedAt` 倒序（最近置顶优先）；其后 `sortOrder`；最后 `createdAt`；极端同值时按 `id` 稳定排序。接口返回顺序与前端 `sortStories()` 一致。
- 搜索覆盖标题、正文、分类名；大小写不敏感；命中数实时显示。
- 删除故事、删除分类均二次确认；分类非空时删除入口置灰并提示“分类下还有 N 篇故事”。
- 全文弹窗打开时锁定背景滚动；Esc、遮罩点击、关闭按钮均可关闭；弹窗内复制与卡片复制行为一致（仅正文）。
- 空状态分三种：无故事、分类为空、搜索无结果。
