## 1. 需求 R-008 有效的提问（P1，v1）

- **来源**：CR-008（2026-11-18，G0 确认：空页面人工维护、备注不进入复制、无随机、位于咨询树之后）。
- **背景**：咨询师需要好问题打开话题，问法散落在个人笔记；同一个问题对不同学生的效果不同，需要一条只有咨询师能看到的备注记录适用场景与追问方式。
- **描述**：后台“咨询”组新增“有效的提问”，位于“咨询树”之后。左侧分类，右侧提问卡片；支持按分类筛选、搜索、复制、置顶、新增、编辑、删除；每道题有一条咨询师备注（可为空），在卡片上展示并可单独编辑。分类可新增、改名、上下调序，非空不可删。首期空页面，全部人工维护。
- **成功指标**：
  - 进入页面到复制一个问题 ≤ 3 次操作。
  - 加备注后刷新仍在；复制结果只含提问正文。
  - 可观察场景：新建“开场”，添加“你最近一次觉得时间过得特别快是什么时候？”，备注“冷场时用，追问细节”；复制得到问题原文，不含备注。
- **验收标准**：

  - `AC-008-1` 侧栏“咨询”组顺序为 写咨询稿 → 咨询树 → 有效的提问；点击进入 `/admin/consult/questions`，页面标题“有效的提问”，浏览器标题“有效的提问 · 管理后台”；分组高亮。
  - `AC-008-2` 分类栏显示“全部提问”“置顶”和已有分类，计数正确；切换分类只显示该类并高亮；切回全部恢复；无分类时显示“先新建一个分类”，新增按钮禁用或提示。
  - `AC-008-3` 搜索覆盖提问正文、备注与分类名；实时过滤、显示结果条数；清空恢复；无结果显示空状态。
  - `AC-008-4` 复制只复制提问正文，不含备注与分类；按钮短暂显示“已复制”；连续复制不同条目正确。
  - `AC-008-5` 置顶：☆ → ★，置顶区内按最近置顶排最前；“置顶”筛选与计数正确；刷新保持；取消置顶回原顺序。
  - `AC-008-6` 新增 / 编辑 / 删除：选择分类、填写正文后保存，新条目排在该分类末尾，计数 +1；正文为空的保存被拒绝；编辑正文 / 分类 / 备注 / 置顶后列表立即反映；删除二次确认后移除、计数 -1。
  - `AC-008-7` 备注：每道题一条，可为空；卡片上展示（无备注显示“加备注”入口）；点击“编辑备注”打开小弹窗，保存后立即更新、刷新保持；备注不进入复制内容、不影响排序。
  - `AC-008-8` 分类管理：新增排末尾；改名同步分类栏与卡片；上移 / 下移立即生效且刷新保持；非空分类删除禁用并提示条数（接口 409 带 `count`）；空分类可删；空名 / 重名被拒绝。
  - `AC-008-9` 与金句栏、故事集、专业知识汇总、收藏栏互不影响：导航其余入口顺序不变；接口与数据独立。
  - `AC-008-10` 异常与鉴权：未登录 401；分类不存在、正文或备注超长 400；不存在 404；请求失败显示错误与重试，不白屏。

## 3. 关键设计

### 3.1 信息架构

- 路由：`/admin/consult/questions`，名称 `admin-consult-questions`，标题 `有效的提问 · 管理后台`。
- 导航：咨询组 写咨询稿 → 咨询树 → **有效的提问**；`activeGroup` 仍归“咨询”。
- 布局沿用金句栏：左分类栏（全部提问 / 置顶 / 各分类 / 管理分类）+ 右侧搜索与卡片列表；≤1000px 分类栏收为横向标签条。
- 卡片：提问正文（完整显示，过长折叠）、分类名、备注区（有备注显示内容，无备注显示“加备注”）、复制按钮、编辑备注入口；悬停显示置顶、编辑、删除。
- 顶部动作：新增提问（无“随机”）。

### 3.2 数据模型

```sql
CREATE TABLE IF NOT EXISTS consult_question_categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_consult_question_categories_name
  ON consult_question_categories(name);
CREATE INDEX IF NOT EXISTS idx_consult_question_categories_order
  ON consult_question_categories(sort_order, id);

CREATE TABLE IF NOT EXISTS consult_questions (
  id TEXT PRIMARY KEY,
  category_id TEXT NOT NULL,
  text TEXT NOT NULL,
  note TEXT NOT NULL DEFAULT '',
  pinned INTEGER NOT NULL DEFAULT 0,
  pinned_at TEXT NOT NULL DEFAULT '',
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_consult_questions_category
  ON consult_questions(category_id, pinned DESC, pinned_at DESC, sort_order, created_at);
```

- 不启用数据库外键；分类存在性、删除限制在接口层校验。
- 置顶排序与故事集一致：`pinned DESC → pinned_at DESC → sort_order → created_at → id`。
- 备注只有一条，存在 `note` 字段。

### 3.3 接口契约

统一前缀 `/api/admin/consult`，沿用管理员登录态。

| 方法 | 路径 | 作用 | 成功响应 |
| --- | --- | --- | --- |
| `GET` | `/questions` | 读取全部分类与提问 | `{ categories, questions }` |
| `POST` | `/questions` | 新增提问 | `{ item }` |
| `PATCH` | `/questions/:id` | 编辑正文 / 备注 / 分类 / 置顶 | `{ item }` |
| `DELETE` | `/questions/:id` | 删除提问 | `{ ok: true }` |
| `POST` | `/question-categories` | 新增分类 | `{ category }` |
| `PATCH` | `/question-categories/:id` | 分类改名 | `{ category }` |
| `PUT` | `/question-categories/order` | 全量重排 | `{ categories }` |
| `DELETE` | `/question-categories/:id` | 删除空分类 | `{ ok: true }` |

响应对象：

```ts
interface ConsultQuestionCategory { id: string; name: string; sortOrder: number; count: number }
interface ConsultQuestion {
  id: string; categoryId: string; text: string; note: string;
  pinned: boolean; pinnedAt: string; sortOrder: number;
  createdAt: string; updatedAt: string
}
```

校验与错误：

- 正文 `trim` 后 1–2000 字；备注 `trim` 后 ≤2000 字（可为空）；分类名 1–30 字；否则 `400`。
- 分类重名 `409`；分类不存在 `400`；不存在提问 `404`；非空分类删除 `409` 带 `count`；未登录 `401`。
- 置顶：置顶时写 `pinned_at`，取消清空；已置顶编辑保留原 `pinned_at`。
- 日志只记录 `id` / `categoryId` / `pinned`，不记录正文与备注。

### 3.4 前端结构（新文件 ≤400 行）

- `web/src/views/admin/ConsultQuestions.vue`：页面骨架、数据加载、筛选与搜索状态。
- `web/src/views/admin/questions/QuestionCard.vue`：正文、备注展示、复制、置顶、编辑/删除、编辑备注入口。
- `web/src/views/admin/questions/QuestionFormModal.vue`：新增/编辑表单（正文、分类、备注、置顶）。
- `web/src/views/admin/questions/QuestionNoteModal.vue`：单独编辑备注（小弹窗）。
- `web/src/views/admin/questions/QuestionCategoryModal.vue`：分类管理。
- `web/src/views/admin/questions/useQuestionShelf.ts`：接口调用与本地状态。
- `web/src/views/admin/consultQuestions.css`：样式（类名加 `.questions-page` 前缀，避免全局泄漏）。
- `shared/src/consult-question.ts`：类型与长度常量。

交互口径：

- 列表排序与接口一致（置顶最近优先）。
- 复制只取 `text`；备注与分类不进入剪贴板。
- 删除提问 / 分类二次确认；分类非空时删除置灰并提示条数。
- 空状态三种：无提问、分类为空、搜索无结果。
- 390px：分类栏横向标签条，卡片不横向溢出，备注长文本自动换行。
