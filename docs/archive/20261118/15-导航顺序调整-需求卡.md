## CR-009 咨询组导航顺序调整

- **类型**：导航调整
- **问题与价值**：金句栏与故事集是通话中最常用的“可直接引用”的内容，上一轮把它们放进了「知识库 & 数据库」，咨询师在通话中需要跨组切换。把它们放回“咨询”组，并把咨询树移到最后，让通话主链路（写稿 → 引用 → 提问 → 树状整理）按使用频次排列。
- **描述**：调整侧栏分组归属与顺序：
  - 咨询：写咨询稿 → 金句栏 → 故事集 → 有效的提问 → 咨询树
  - 知识库 & 数据库：升学分数线查询 → 专业知识汇总
- 金句栏、故事集从知识库组迁回咨询组；路由、页面、接口、数据、功能全部不变。
- **成功指标**：
  - 咨询组五项按上述顺序显示，知识库组两项。
  - 金句栏 11 类 140 条、故事集数据与操作与调整前一致。
  - 旧链接 `/admin/consult/quotes`、`/admin/consult/stories` 仍可直接访问。
- **验收标准**：

  - `AC-009-1` 侧栏分组顺序为 问卷 → 咨询 → 知识库 & 数据库 → 设置；咨询组为 写咨询稿 → 金句栏 → 故事集 → 有效的提问 → 咨询树；知识库组为 升学分数线查询 → 专业知识汇总。
  - `AC-009-2` 点击金句栏进入 `/admin/consult/quotes`，页面标题、11 类 140 条、复制、置顶、分类管理不变；分组高亮为“咨询”。
  - `AC-009-3` 点击故事集进入 `/admin/consult/stories`，页面、分类与故事数据、搜索、复制、置顶、增删改不变；分组高亮为“咨询”。
  - `AC-009-4` 高亮映射：写咨询稿/咨询树/有效的提问/金句栏/故事集/收藏栏直达 → 咨询组；分数线/专业知识汇总 → 知识库组；概览/邀请/学员名单 → 问卷组；设置三项 → 设置组。
  - `AC-009-5` 390px 下咨询组五个入口完整显示，无横向溢出、无重叠；知识库组两项正常。
  - `AC-009-6` `npm run verify` 全绿；版本 `1.97.0` 与 README、development-history、04、09 一致。

- **NFR**：性能/安全/隐私/成本不适用；兼容性适用（路由不变）；可观测性不适用。
- **范围**：仅 `web/src/views/admin/AdminLayout.vue` 的入口位置与 `activeGroup` 判定；版本与文档。
- **不在范围内**：金句栏/故事集功能改造；知识库页面改造；收藏栏恢复；导航配置化。
- **风险**：低；用户需重新适应分组位置。
