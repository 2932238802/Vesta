## 1. 需求 R-006 知识库重组（P1，v1）

- **来源**：CR-006（2026-11-18，G0 已确认）。
- **背景**：金句、分数线、专业知识分散在三个栏目，咨询师通话中要在多个入口之间切换。把“查资料”的内容收进一个「知识库 & 数据库」栏目，并用“专业 → 知识点”的 Wiki 结构组织专业知识。
- **描述**：
  1. 侧栏“分数线”分组改名为「知识库 & 数据库」；
  2. 咨询组移除“收藏栏”入口（页面、接口、数据保留，旧链接可直达）；
  3. 金句栏迁入「知识库 & 数据库」，位于升学分数线查询之下；
  4. 新组内新增“专业知识汇总”：左侧专业，右侧知识点列表，点击进入 Wiki 阅读视图；管理员可维护专业与知识点。
- **成功指标**：
  - 从进入专业知识汇总到打开某个知识点 ≤ 3 次操作（选专业 → 选知识点 → 阅读）。
  - 新建专业与知识点后刷新仍存在，列表与计数一致。
  - 可观察场景：新建“护理”，添加“专科和本科的就业对比”，点击后看到带面包屑的阅读页，Markdown 正常渲染，返回后仍在护理专业页。
- **验收标准**：

  - `AC-006-1` 侧栏分组顺序为 问卷 → 咨询 → 知识库 & 数据库 → 设置；「知识库 & 数据库」组内顺序为 升学分数线查询 → 金句栏 → 专业知识汇总；咨询组为 写咨询稿 → 咨询树 → 故事集，**不再显示收藏栏**。
  - `AC-006-2` 收藏栏仅移除入口：直接访问 `/admin/consult/collections` 仍正常渲染，列表与详情可用，接口与数据不变。
  - `AC-006-3` 金句栏入口位于新组内，点击进入 `/admin/consult/quotes`，页面、11 类 140 条数据、复制、置顶、分类管理均与之前一致；浏览器标题仍为“金句栏 · 管理后台”。
  - `AC-006-4` 打开 `/admin/knowledge`：无专业时显示引导“先新建一个专业”，新增专业后出现在左侧并高亮；专业支持改名、上移/下移且刷新保持；空专业可删除，有知识点时删除禁用或返回 409 并提示条数；专业名为空或重复被拒绝。
  - `AC-006-5` 在专业下新增知识点：填写标题与正文后保存，出现在该专业列表末尾，计数 +1；编辑后立即反映；删除二次确认后移除、计数 -1；标题或正文为空被拒绝。
  - `AC-006-6` 点击知识点进入 Wiki 阅读视图：面包屑为「专业知识汇总 / 专业名 / 知识点标题」，正文按 Markdown 渲染（标题、加粗、列表、链接、代码），“返回”回到该专业首页；直接访问 `/admin/knowledge/:majorId/:articleId` 可打开同一篇。
  - `AC-006-7` Markdown 安全：正文中的原始 HTML / `<script>` 以文本显示，不执行；链接只允许 http/https，`javascript:` 链接不生成可点击元素；页面不使用不可信 `v-html`。

### 3.1 信息架构

### 3.2 数据模型

```sql
CREATE TABLE IF NOT EXISTS knowledge_majors (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_knowledge_majors_name
  ON knowledge_majors(name);
CREATE INDEX IF NOT EXISTS idx_knowledge_majors_order
  ON knowledge_majors(sort_order, id);

CREATE TABLE IF NOT EXISTS knowledge_articles (
  id TEXT PRIMARY KEY,
  major_id TEXT NOT NULL,
  title TEXT NOT NULL,
  body TEXT NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_knowledge_articles_major
  ON knowledge_articles(major_id, sort_order, created_at);
```

- 不启用数据库外键；专业存在性、删除限制在接口层校验。
- 知识点顺序：`sortOrder` 升序、`createdAt` 兜底；新增排在该专业末尾。
- 不设置置顶、标签、版本字段。

### 3.3 接口契约

统一前缀 `/api/admin/knowledge`，沿用管理员登录态。

| 方法 | 路径 | 作用 | 成功响应 |
| --- | --- | --- | --- |
| `GET` | `/` | 专业列表 + 知识点摘要（不含正文） | `{ majors, articles }` |
| `GET` | `/articles/:id` | 单篇正文 | `{ article }` |
| `POST` | `/articles` | 新增知识点 | `{ article }` |
| `PATCH` | `/articles/:id` | 编辑标题 / 正文 / 所属专业 | `{ article }` |
| `DELETE` | `/articles/:id` | 删除知识点 | `{ ok: true }` |
| `POST` | `/majors` | 新增专业 | `{ major }` |
| `PATCH` | `/majors/:id` | 专业改名 | `{ major }` |
| `PUT` | `/majors/order` | 全量重排 | `{ majors }` |
| `DELETE` | `/majors/:id` | 删除空专业 | `{ ok: true }` |

响应对象：

```ts
interface KnowledgeMajor { id: string; name: string; sortOrder: number; count: number }
interface KnowledgeArticleSummary {
  id: string; majorId: string; title: string; sortOrder: number;
  createdAt: string; updatedAt: string
}
interface KnowledgeArticle extends KnowledgeArticleSummary { body: string }
```

校验与错误：

- 专业名 `trim` 后 1–30 字；重名 `409`。
- 标题 `trim` 后 1–120 字；正文 `trim` 后 1–50000 字；否则 `400`。
- `majorId` 必须存在；换专业时 `sort_order` 置为新专业末尾。
- `PUT /majors/order` 的 `ids` 必须恰好是现有全部专业的一个排列，否则 `400`；单事务写入。
- 删除非空专业 `409`，响应含 `count`；不存在 `404`；未登录 `401`。
- 日志只记录 id / majorId / count，不记录标题与正文。

### 3.4 前端结构

为满足“新文件 ≤400 行”：

- `web/src/views/admin/KnowledgeBase.vue`：页面骨架、路由参数、数据加载与错误态。
- `web/src/views/admin/knowledge/MajorRail.vue`：专业列表、新增/管理入口、窄屏标签条。
- `web/src/views/admin/knowledge/MajorHome.vue`：专业首页（知识点列表、添加/编辑/删除入口）。
- `web/src/views/admin/knowledge/ArticleView.vue`：Wiki 阅读视图（面包屑、Markdown 渲染、返回）。
- `web/src/views/admin/knowledge/ArticleEditorModal.vue`：知识点编辑（标题、专业、正文、Markdown 预览）。
- `web/src/views/admin/knowledge/MajorModal.vue`：专业新增 / 改名 / 调序 / 删除限制。
- `web/src/views/admin/knowledge/useKnowledge.ts`：接口调用与本地状态。
- `web/src/views/admin/knowledge.css`：样式。
- `web/src/api/knowledge.ts` + `api/types.ts`：请求方法与类型。

交互口径：

- 阅读视图使用 `renderMarkdown`（现有 `web/src/markdown.ts`），禁止直接插入未经处理的用户 HTML。
- 编辑弹窗提供“编辑 / 预览”切换，预览复用同一渲染函数。
- 未选专业时显示欢迎页与“新建专业”；空专业显示“还没有知识点”。
- 删除专业、删除知识点均二次确认；专业非空时删除入口置灰并提示条数。
- 390px：专业栏变横向标签条，阅读视图面包屑可换行，正文图片 `max-width: 100%`。
