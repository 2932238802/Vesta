## 1. 需求 R-009 导航顺序调整（P2，v1）

- **来源**：CR-009（2026-11-19，G0 确认）。
- **背景**：金句栏与故事集是通话中最常用的引用内容，上一轮放进知识库组导致跨组切换；咨询树使用频率低。
- **描述**：调整咨询组与知识库组的入口归属与顺序：
  - 咨询：写咨询稿 → 金句栏 → 故事集 → 有效的提问 → 咨询树
  - 知识库 & 数据库：升学分数线查询 → 专业知识汇总
  - 路由、页面、接口、数据、功能不变。
- **成功指标**：
  - 咨询组五项、知识库组两项按顺序显示。
  - 金句栏 140 条与故事集数据不变。
  - 旧链接直接可访问。
- **验收标准**：

  - `AC-009-1` 分组顺序 问卷 → 咨询 → 知识库 & 数据库 → 设置；咨询组 写咨询稿 → 金句栏 → 故事集 → 有效的提问 → 咨询树；知识库组 升学分数线查询 → 专业知识汇总。
  - `AC-009-2` 金句栏页面与数据（11 类 140 条）、复制、置顶、分类管理不变，高亮归“咨询”。
  - `AC-009-3` 故事集页面与数据、搜索、复制、置顶、增删改不变，高亮归“咨询”。
  - `AC-009-4` 高亮映射：写咨询稿/咨询树/有效的提问/金句栏/故事集/收藏栏直达 → 咨询；分数线/专业知识汇总 → 知识库；概览/邀请/学员名单 → 问卷；设置三项 → 设置。
  - `AC-009-5` 390px 咨询组五入口完整、无溢出、无重叠。
  - `AC-009-6` `npm run verify` 全绿；`1.97.0` 与 README、development-history、04、09 一致。

- **NFR**：

| 项 | 判定 | 目标 / 理由 |

| 性能 / 安全 / 隐私 / 成本 | 不适用 | 纯导航位置调整。 |
| 兼容性 | 适用 | 路由不变，旧书签可用。 |
| 可观测性 | 不适用 | 无新增日志。 |

- **影响面**：`web/src/views/admin/AdminLayout.vue`（入口位置与 `activeGroup`）；版本与文档。
- **不在范围内**：功能改造；收藏栏恢复；导航配置化。
- **变更历史**：v1 2026-11-19 初始。
