## 3. 引用与命令约定

- 代码定位一律写 `路径#符号`，例如 `server/src/ai/report-queue.ts#enqueueReport`。行号只在引用稳定配置块时使用，并附带 commit。
- 命令块统一给出：**cwd**、**预期可 grep 的输出**、**退出码**、**失败后看哪里**。
- 占位符只允许以下 7 个，使用时必须在同段说明替换来源：

| 占位符 | 替换来源 |
| --- | --- |
| `<HOST>` | 部署机地址或回环地址 |
| `<PORT>` | `.env` 的 `PORT`，默认 `8787` |
| `<DOMAIN>` | 反向代理对外域名 |
| `<USER>` | 部署机系统用户 |
| `<TOKEN>` | 管理员登录后返回的 Bearer Token |
| `<DB_NAME>` | `DATA_DIR/vesta.db` 的数据库文件名 |
| `<BUCKET>` | 备份目标对象存储桶名（若使用） |

- 不写真实密钥、Token、账号、域名、IP、内网地址。发现硬编码凭证时写 `<已脱敏>` 并登记到 [AGENT.md](./AGENT.md) 的待确认清单。
- 不复制大段源码；确需示例时 ≤ 15 行，并说明“为什么必须贴”。
