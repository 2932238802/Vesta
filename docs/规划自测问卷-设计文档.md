# 大学四年规划自测问卷 · 设计文档 v1.0

> 用途：给顾问在「维护环节」发给学员填写，答完自动生成一份诊断报告，作为打电话前的判断依据和通话弹药。
> 本文档是给开发/执行 agent 的唯一口径，按此实现，不要自行增删题目或改动选项顺序。

---

## 一、目的与场景

**业务流程位置**：三天直播课 → 助教官微把链接发给学员（要暗号）→ 学员还没真正去听课，中间有 1–3 天空档 → 顾问以「学姐」身份做维护 → 发这份问卷。

**这份问卷要同时完成四件事**
1. 让学员知道「英语这件事对自己重要」（但不是靠问卷硬推，而是靠目标倒推出来）。
2. 让学员自己说出痛点、难点、卡点（原话后面要进报告和电话）。
3. 让学员承认「我现在这样下去不行」。
4. 给顾问一个专业身份：我是给你做过诊断的人，不是来卖课的。

**问卷不能做的事**
- 不能只问英语（功利性太强，会被识别成卖课）。
- 不能问生活费、谁出钱、家里对报课的态度（必被拉黑）。
- 不能出现「报班」「课程」「学费」等字样。

**名头**：大学四年规划自测 · 学姐帮你看看现在在哪儿
**开场语**：「这不是英语测试，也不考你什么。我想先知道你现在是什么情况、想去哪，才好在电话里给你做规划。大概 8 分钟，答完我这边会给你一份分析。」
**隐私说明**（放在开场语下方小字）：「这份只用于给你做规划，不会外传。」

---

## 二、目标用户

- 双非二本、专科、民办本科的大一到大四学生，以大一、大二为主。
- 家庭普通，对专业和就业不了解，决策会牵扯家人。
- 手机填写为主，耐心低，任何一题超过 3 个屏就会流失。

---

## 三、结构总览

- 共 **27 题**，分 4 部分，预计 8 分钟。
- 客观选择题 24 题，填空 3 题（专业、想做的行业岗位、五年后的自己）。
- 单屏一题，点选自动进入下一题；填空题为单独一屏，有「下一步」按钮。
- 顶部固定进度条：「已答 12 / 27」。

## 六、报告自动生成规则

报告目标只有一个：**让她知道自己的痛点，有紧迫感。** 不推报名。

### 6.1 一句话结论（开头第一句）
模板：`你现在不是「{表面问题}」，是「{真实卡点}」。`

- 依据：Q1 学校层级 + Q11 方向清晰度 + Q13 执行力 + Q16 信息差。
- 例：
  - 方向清楚但信息差大 → 「你不是不努力，是不知道该往哪儿使劲。」
  - 方向模糊但执行力强 → 「你不是懒，是没人告诉你该做什么。」
  - 三者都弱 → 「你现在的状态，是四年里最常见的开局，但它不改，到大三会动不了。」

### 6.2 卡在哪一层（只写一个最卡的点）
依据 Q17–Q22，按优先级取一个：
- 词汇层：Q21 = 背了忘 / 基本不背
- 听力层：Q22 = ①，且 Q18 = 听力
- 开口层：Q22 = ①或②
- 方法层：Q19 = 几乎没学，或 Q20 < 3 小时
- 时间层：Q20 = 少于 3 小时，但 Q13 = ①（想学没时间）
每个层级配一句「这个层级在考试里长什么样」。

### 6.3 什么时候要命（给具体日期）
依据 Q3 + Q6 + 考试日历倒推：「你离 {下次关键节点} 还有 {N} 个月」。
- 四级：每年 6 月、12 月
- 教资：每年 3 月、9 月
- 考研：每年 12 月
- 专升本：多数省份 3–4 月
- 就业：大三暑假实习、秋招 9–11 月

### 6.4 五年后的画面
引用 Q26 原话 + Q8 城市 + Q5a 岗位，写一段她能认出来的画面，不要写鸡汤。

### 6.5 分层给顾问（不进报告，只在后台）
| 优先级 | 条件 |
|---|---|
| A 优先打 | 学校层次 ≥ 一本，或 Q11 ≥ ②且 Q13 = ①，且 Q16 ≤ ② |
| B 可养 | 有目标但信息差大（Q16 = ③/④），或执行力中等 |
| C 先放 | Q13 = ④ 且 Q11 = ④ 且 Q19 = 几乎没学 且 Q20 < 3 小时 → 摆烂型，顾问不必花时间 |

> 这一条是「把摆烂的 pass 掉」的落点：不是删选项，是在后台打标，排序时沉底。

### 6.6 报告长度
800–1200 字，5 个小标题，不超过 2 个屏。

## 七、交互与视觉

- 移动端优先，最大宽度 640px，桌面居中。
- 单屏一题，选项点击后 250ms 自动进入下一题；有「上一题」小按钮。
- 进度条固定在顶部，显示「已答 X / 27」。
- 多选用「下一步」按钮确认。
- 数字题用 0–10 滑块，实时显示数值。
- 提交后先出**简版结论**（3 句话），下方按钮「复制完整结果」，方便学员发给顾问。
- 可关闭提示：「答完这页，我整理一份完整的发你」——给顾问留介入点。
- 埋点：每题停留时长、在第几题放弃、总时长。后端记录。
- 视觉：白底、深灰字、一个主色（蓝 #2f6c9e），圆角卡片，不要花哨插画。
