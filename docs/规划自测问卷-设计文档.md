### v1.5（2026-11-13）——英语块校验误伤与漏拦订正

- 依据：`docs/archive/20261113/6-英语块校验-review报告.md`。v1.67 的校验层有 3 处残留：考研 + 听力按共现误伤、口语 / 时长正则覆盖不全或偏严、第 5 篇分析稿的题号过期。
- 考研 × 听力：只有同段确实出现考试语义（初试 / 复试 / 考试 / 科目 / 要考 / 加试 / 计入 / 占 N 分）且听力被写成「要考 / 计入 / 占分」时，才要求限定为复试或雅思托福；单纯「考研」和「听力」共现（如「考研和听力是两件要一起抓的事」）不再判错。
- 口语：反向语序（「不追求口语流利」）、「放一放 / 缓一缓 / 靠后 / 以后再说」和跨行写法同样拦截；带否定的正确表述（「口语不能往后放」）放行。
- 英语块时长：只拦复述问卷的每周投入 / 总时长（如「每周 5 小时」「总共 17.5 小时」）；「每周末做一套真题」「每天 1 小时听力」这类练习节奏不算重复。

## 一、目的与场景

**业务流程位置**：三天直播课 → 助教官微把链接发给学员（要暗号）→ 学员还没真正去听课，中间有 1–3 天空档 → 顾问以「学姐」身份做维护 → 发这份问卷。

**这份问卷要同时完成四件事**

1. 让学员知道「英语这件事对自己重要」（但不是靠问卷硬推，而是靠目标倒推出来）。
2. 让学员自己说出痛点、难点、卡点（原话后面要进报告和电话）。
3. 让学员承认「我现在这样下去不行」。
4. 给顾问一个专业身份：我是给你做过诊断的人，不是来卖课的。

**问卷不能做的事**

- 不能只问英语（功利性太强，会被识别成卖课）。
- 不能问生活费、谁出钱、家里对报课的态度（必被拉黑）。
- 不能出现「报班」「课程」「学费」等字样。

**名头**：大学四年规划自测 · 我帮你看看现在在哪儿

**开场语**：「这不是英语测试，也不考你什么。我想先知道你现在是什么情况、想去哪，才好在电话里给你做规划。大概 8 分钟，答完我这边会给你一份分析。」

**隐私说明**（放在开场语下方小字）：「这份只用于给你做规划，不会外传。」

---

## 二、目标用户

- 双非二本、专科、民办本科的大一到大四学生，以大一、大二为主。
- 家庭普通，对专业和就业不了解，决策会牵扯家人。
- 手机填写为主，耐心低，任何一题超过 3 个屏就会流失。

## 六、报告自动生成规则

报告目标只有一个：**让她知道自己的痛点，有紧迫感。** 不推报名。

### 6.1 一句话结论（开头第一句）

- 由 AI 根据本次答卷写，必须落到一个具体回答或系统数字上，不套固定句式。
- 不再使用「你不是 X，是 Y」模板；同一个 Skill 下，不同答卷的结论必须不同。

### 6.2 报告模块（程序定结构，AI 写判断）

程序先按答卷生成 `moduleSpecs`，AI 只能在该结构内写标题、一句话判断、正文和逐项解释：

- `scorecard`：九项分数。分数全部由 `shared/src/docScore.ts` 按 Q1/Q5/Q6/Q9/Q12/Q13/Q15/Q16/Q17/Q18/Q19/Q25/Q27 等回答计算，AI 不加减乘除。
- `assets`：只列 Q12 / Q13 / Q18 里已经存在的资源；一条都没有时整块不显示，不用安慰句凑数。
- `jobmap`：按专业方向挂真实招聘原文，逐条写「你符合 / 你还缺」；某个方向没有检索结果时整个方向不显示。同一方向内原文对专业的写法不一致时，方向卡必须写明「这几条原文对专业的写法不一致，以具体岗位为准」，不能只取其中一条的说法；`relatedJobs` 是方向外的原文，卡片要注明「这条原文写的是另一类岗位」；有过期原文参与的方向，`entry` 必须以「仅看要求结构，不能当投递入口」开头。
- `gap`：只列程序能从答卷算出的事实——第一选择、关键时间窗、目标城市、目标岗位、专业、现在能写进简历的内容、期望薪资、经济约束、英语现状和每周投入；简历里一项都写不出来时，这一行也必须保留并写「还没有」，不能省略；「入场线」「城市判断」「下一步」这类分析必须由 AI 写在 summary / paragraphs 里，程序不再生成通用建议句。没有数据的行不补（简历盘点为空本身是事实，要写出来）。
- `roadmap`：节点和剩余月份由程序算，阶段只排时间窗，阶段名、主目标和可验证产出由 AI 写；没有每周投入数据时不做总时长估算。
- `checklist`：给出可以自己去核对的检索入口，不写结论。
- 英语块、卡点、时间窗、五年后画面：数据由程序给，解释由 AI 写。英语块另受以下写作约束：
  - 听力和口语不是二选一，两样都要补；不得写「先补听力，再补口语」「口语不追求流利」「等口语流利了再练」这类替学生降低口语目标的排序。只有答卷材料明确给出先后时才写顺序，否则写「两样都要补，听力可以单独成线，口语同步练」。反向语序（如「不追求口语流利」）、换词（「放一放」「缓一缓」「靠后」「以后再说」）和跨行写法同样不允许；带否定的正确表述（如「口语不能往后放」）不受影响。
  - 「学不好的原因」是 Q24 多选题，学生选了几项就逐条对应几项，不能把多选压成单一原因，也不能补写学生没选的原因。
  - 验证方法可以写成建议（如「同一套真题隔一段时间重做，看错处是不是同一类」「听完一段用自己的话复述、录音回听」），但要标明是建议，不能写成学生现在已经在做的做法。
  - 可以补一句大学课堂的一般局限（如课堂上以讲语法、讲课文为主，很少单独教怎么练听力、怎么判断真的听懂了），但不评价具体学校或老师。
  - 英语块只写怎么补、怎么验证，不复述问卷的每周投入和总时长（如「每周 5 小时」「总共 17.5 小时」）；「每周末做一套真题」「每天 1 小时听力」这类练习节奏属于怎么补，可以写。
- 模块副标题（如「0—10 分，按你的回答算出来，不是感觉」「只列答卷里已经有的，不凑数」）和结构标签是程序固定的系统说明，不属于 AI 分析正文；AI 负责标题、一句话判断、正文和逐项解释。
- **跨模块一致性**：生成后要校验各模块说的是同一件事，不能同一份报告里各说一套。`gap` 若写「只有一项空着」这类整体结论，而评分卡里技能或实习低于 3 分，判矛盾并要求重写；方向卡内原文对专业写法不一致时必须注明，方向外原文必须标「另一类岗位」；有过期原文参与的方向 `entry` 缺「仅看要求结构，不能当投递入口」前缀，同样重写。英语听力不能和考试科目说错：同一段里「考研」和「听力」共现，且确实写了考试语义（初试 / 复试 / 考试 / 科目 / 要考 / 加试 / 计入 / 占 N 分）与「听力被考 / 计入 / 占分」时，必须写明是复试或雅思/托福类考试——考研初试不考听力，不能把「听力弱」直接写成初试要考；单纯把「考研」和「听力」并列（如「考研和听力是两件要一起抓的事」）不判错。校验放在生成阶段，不改 AI 正文为模板句。
- **全报告去重（生成阶段）**：同一件事整份报告只讲一次，去重发生在生成/校验阶段，不在渲染层删文字。时间距离只保留 `gap` 的「关键时间窗」和 `roadmap` 副标题两处，开头结论、模块标题和正文不再复述「还有约 X」「距离 X」「X 年后」；英语的每周投入和总时长只在 `roadmap` 副标题出现一次，英语块只写怎么补、怎么验证（英语块复述问卷的每周投入 / 总时长，如「每周 5 小时」「总共 17.5 小时」，即判重复；「每周末做一套真题」这类练习节奏不算）；目标城市统一用 `resolveTargetCity()` 落到的具体城市，不回抄 Q9 选项原文（如「新一线（杭州、成都、武汉、西安等）」）；「简历上缺一段和目标方向对得上的经历」这类整句最多出现一次，岗位卡只写这条原文的具体要求；过期原文提示由岗位块副标题统一给一次，卡片只保留「信息较早」标签。校验不通过先把具体问题反馈给 AI 重写一次，仍在则整份报告失败（`AI 报告重复：…`），不把重复正文写进报告。

没有证据的模块或条目直接不出现，AI 不得补写系统未提供的分数、比例、岗位或时间。

### 6.3 时间距离

所有对外时间距离统一走 `shared/src/date.ts`，按日历差计算并输出粗粒度中文：两年 / 三年、一年 / 一年半、X 个月、不到一个月、已过去 X。

- 不允许出现「还有 547 天」「24 个月」「2 年」这类数字加时间单位的写法；生成后会扫描并重写。
- 时间距离的展示位置按 6.2 的全报告去重：只保留 `gap`「关键时间窗」和 `roadmap` 副标题两处，其余模块不再复述。
- 关键节点仍按 Q3 + Q7 + 考试日历倒推：四级 6 月/12 月、教资 3 月/9 月、考研 12 月、专升本多数省份 3–4 月、就业看大三暑假实习和秋招 9–11 月。
- 跨年、闰日 2/29、月末 31 日、整年和已过期等情况由 `shared/src/date.cases.ts` 覆盖；该脚本已接入 `npm run verify`（`check:dates`），不再只靠手工执行。
- 月末按「从起点加完整月、日数截断」计算：2024-01-31 加 1 个月是 2024-02-29；余下的 `days` 恒为非负，`totalMonths` 仍决定粗粒度展示。

### 6.6 报告生成方式

- 分析规则唯一来源是后台 `/admin/skill` 当前启用的模板；模板为空或找不到时直接报错，不回退模板报告。后台删除当前启用的自定义模板时会显式改回默认设置；除此之外 activeId 指向不存在的模板时直接报错。
- AI 只写文字：结论、模块标题、一句话判断、正文和逐项解释。分数、月份、阶段、岗位门槛和来源全部由程序给出；检索过程（检索词、查询变体、丢弃原因）只进后台日志，不展示给答卷人。
- 生成后做数字审计：AI 文本里出现系统未提供的数字就重写一次，仍不通过则整份报告失败，不把错数字写进报告。`scorecard` 的分数单独校验：每个 item 的文本里，`N 分`、`得分 N`、`N/10` 必须等于该 item 的系统分数；模块 summary（页面「可提升空间」正文）里提到的分数必须是本模块某一项的系统分数，写别的 item 的分数同样判失败。「0—10 分」「满分 10 分」「10 分制」属于量纲说明，不参与比对。
- 需要外部信息时由服务端主动调用博查，按 6.7 的口径检索；未配置、超时或失败只显示结果性说明（如「本次没能获取招聘原文，可稍后重试」），完整原因进后台日志。报告已经生成时，检索记录不再给出必然 409 的「重新检索」按钮，改为提示需要新建报告；生成失败页仍保留重试。
- 生成中展示加载画面；失败显示真实原因和「重新生成」，**不得用低质量兜底模板伪装成 AI 成功**。

### 6.7 招聘检索口径（2026-11-14 定，取代 v1.63 的「固定检索当年 + 届」）

依据 `docs/archive/20261114/6-招聘检索重构-检索计划与证据判定-修复方案.md`。目标不是换数据源，而是让「学生原话 → 可检索的岗位词」和「搜索结果 → 可核对的岗位详情页」各走一套明确规则。

- **时间不变量**：门槛只有一个数——今天往前 **12 个完整月**（2026-11-14 → 2025-11-14），每天滚动，统一走 `isOlderThanMonths(date, 12)`。`JOB_MAX_AGE_MONTHS`、`isStaleJob`、入选、补位、展示、统计和 AI 证据全部同源，不存在第二个时间口径。日期证据取三源中最早的一条：博查 `datePublished`、标题里的年份、摘要里的「发布 / 更新 / 发布时间」；任一证据早于门槛即淘汰。**没有任何日期证据的页面不进岗位卡片**（可留在后台观测）。可用原文不足 3 条时不得用过期页凑数，宁可比 3 条少，甚至 0 条。
- **岗位词清洗**：先去掉「都可以 / 都行 / 随便 / 想当 / 还没想好 / 吧」这类口语、停用词和标点，再按岗位词典取岗位名；抽不出岗位（或只写了专业）时走 `jobDirections(专业)`。清洗后的岗位词用于检索词和核对清单；Q6 原话只作报告展示，不进检索词。
- **检索计划**：变体互不相同，按「通用 → 应届生求职网 → 猎聘 → 专业方向 → 低年级实习」逐级换词；大一 / 大二在通用词之后加一条「实习」。每份报告最多 **4 次**博查外呼，同一检索字符串只跑一次；可用原文 ≥3 条且方向覆盖完整即停；每次升级必须换词并记录原因。**不再拼「届」**，改由「应届 / 实习」+ 12 个月窗控制时效；旧报告里已存的届别年份不篡改。
- **证据判定**：一条结果要同时满足「详情页 + 岗位证据 + 相关」才收。详情页看 URL 的岗位路径 / 岗位 ID，或标题里的公司名 / 岗位名，或摘要里的「岗位职责 / 任职要求 / 薪资 / 地点」；岗位证据看薪资区间、经验 / 学历要求、招聘人数 / 截止日期（命中 ≥2 项），或「招聘 + 公司名 + 地点」3 项弱证据；相关性看清洗后的岗位词或方向同义词是否出现在标题 / 摘要。门户页只在「标题去掉站点后缀后既没有公司名也没有岗位名」时拒绝，不因标题含站点词整页砍。
- **内部规则不外露**：问卷不承载任何检索参数。报告只展示岗位卡、来源条数、核对时间和结果性说明（0 条时写「近期没有可核对的招聘原文」），不展示原始检索词、时间窗数字、`freshness` / `site:` / 博查 / 缓存 / 正则、届别拼写或 `BOCHA_*` 配置错误；完整检索词与丢弃原因进后台日志和报告元数据。核对清单里的「自查检索词」用清洗后的岗位词，属于给用户的行动建议，不算内部检索词。
- **可观测与回归**：每次外呼记录 `returned / passed / dropReason`，结束时记录岗位数与日期分布。`server/src/ai/doc-search.cases.ts` 覆盖本次 4 条垃圾页、北极星岗位页、联想英文岗位页、2018 / 2022 / 2024 旧样本、无日期样本和考试报名页；`npm run check:search` 不带参数跑回归，带检索词时打印原始返回与逐条判定。
