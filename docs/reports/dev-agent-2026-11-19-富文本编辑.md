## 8. 偏差与假设

- `[假设]` 转换器额外支持 `h1~h6` 与 `img`：需求只列 `h2/h3/...`，但已有内容可能含更高层级标题或图片；按“降级为文本 / 保留文本”原则，保留标题层级与 Markdown 图片语法，避免保存时丢内容（AC-014-6）。
- `[假设]` 编辑器额外接受可选 `maxlength` / `placeholder` props：用于承接原 textarea 的 50000 字上限与占位提示；未改变需求行为。
- `[实现细节]` Chromium 的 `execCommand('bold'/'italic')` 生成 `<b>` / `<i>`，转换器同时支持 `<strong>` / `<em>`；不影响 Markdown 输出。
- `[实现细节]` 收藏栏真正的编辑控件在 `ConsultCollections.vue`；`ConsultCollectionDetail.vue` 仅跳转，未做无意义改动。
- `[边界]` 表格 / 未知块降级为纯文本，格式会丢失但文字保留；URL 按 `markdown.ts` 规则：http/https、单个 `/` 站内路径、普通相对路径保留，`//host` 与其他协议按文本输出。
- `[记录]` P3-2：`maxlength` 回退会重建 DOM，光标回到开头；按评审结论本轮不扩大范围。
- `[记录]` P3-3：正文文本中的 `*` 可能在再次渲染时被当作强调；按评审结论本轮不扩大范围。
