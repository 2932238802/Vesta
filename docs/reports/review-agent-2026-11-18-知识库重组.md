## 4. 缺陷清单（均 P3）

### [P3] Markdown 外链图片被 CSP 拦截
- 位置：`web/src/markdown.ts:49-53`、`server/src/index.ts:88`（`img-src 'self' data: blob:`）
- 现象：`![图](https://...)` 显示破图并报 CSP 错误；文字/链接/代码不受影响。
- 建议：明确“仅支持站内图片”，或评估受信任域名白名单；本轮不修。
- **处理**：记录；需求卡未把图片列为 AC。

### [P3] `knowledge.css` 为未 scoped 全局样式
- 位置：`KnowledgeBase.vue:340`、`knowledge.css` 的 `.form-row` / `.order-index` / `.breadcrumb` 等
- 风险：后续同名类可能被意外覆盖；当前使用方均为 scoped，未复现。
- 建议：`scoped` 或统一 `.knowledge-page` 前缀。
- **处理**：记录为后续项（直接加 scoped 会影响子组件，需前缀方案）。

### [P3] 阅读视图换专业后 URL 未同步
- 位置：`KnowledgeBase.vue:279-295`、`ArticleView.vue:6-8`
- 现象：在 A 专业阅读页编辑并把知识点改到 B 后，URL 与左侧高亮仍为 A，面包屑指向 B。
- 建议：保存后 `router.replace` 到新专业路由或专业首页。
- **处理**：记录为后续项（不影响数据与 AC）。
