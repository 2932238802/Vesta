# CHANGELOG

> 维护者：Dev ｜ 只写使用者能感知的变化 ｜ 状态：v2.07

## [未发布]

### 新增

- （v2.07）吉林校级线试点：新增长春工程学院、长春师范大学两条校级源与 `school-admit@1` 解析器，抓取官方专升本录取表后自动写入招生专业与专业最低投档分；咨询师选「院校 + 专业」即可看到最低分、计划 / 录取人数与来源。
- 分数线抓取按置信度自动收录：`confidence >= 0.70` 的结果抓完即可查询，无需人工复核。

### 变更

- （v2.07）选专科院校查询时显示「该校为专科院校，不设专升本院校线；请选择接收本科院校」，不再只显示“未收录”。
- （v2.07）产品版本升至 `2.7.0`（v2.07）；`docs/reference/` 版本快照同步到 2.7.0。
- 分数线审核口径改为自动：`confidence < 0.70` 自动标记为不展示（保留记录与来源）；同一内容重抓不改变已通过状态，低置信度新内容不会覆盖已通过的旧数据。
- 存量待处理数据在升级后首次启动时一次性按新口径处理；受影响院校的覆盖看板同步刷新。
- 覆盖看板的 `pending` 改称「历史待定」，表示仅剩历史遗留数据，不再代表有待人工复核的队列。
- 产品版本升至 `2.6.0`（v2.06）；`docs/reference/` 版本快照同步到 2.6.0。

### 修复

- 内容未变的重抓不再显示「抓取失败 / 没有抓到可写库数据」：全部批次跳过时 run 与来源状态为成功，覆盖看板保持上次结果，也不再误报「入口未核验」。
- 启动迁移在覆盖刷新失败时整体回滚（不写完成标记），下次启动会重新处理并补刷覆盖，不会出现「标记已写、覆盖未刷新」的死角。
- 小写 `b区` 写入考研国家线时自动归一为 `B区`，避免写入后按省份查询不到。
- 维度认不出的批次置信度压到自动收录阈值以下，按 `rejected` 留档，不再落入 `approved` 边界。
- 招生计划唯一键迁移改为事务执行，失败时回滚并保留旧索引，下次启动重试。

- 招生计划唯一键补上专业名称：同一院校同年同培养方式下，空专业代码的不同专业不再互相覆盖。
- 考研国家线必须标明 A 区 / B 区，避免写入后按省份查不到。

### 移除

- 后台「复核」队列与「人工导入」入口及其接口已下线（对应请求返回 404）；`scripts/scoreline-data.ts` 仅保留为运维装载脚本。
- 真实学员咨询稿不再随仓库分发：`zxg/` 下 126 个文件已取消 Git 追踪并从工作区删除，`.gitignore` 增加 `/zxg/`；本地素材需自行保管（仓库外备份位于 `_vesta-backups/zxg-20261126-1815`）。
