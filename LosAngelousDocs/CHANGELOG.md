## [未发布]

### 新增

- （v2.10）分数线抓取启动自愈：服务重启后，遗留的「运行中」任务自动标记为失败（提示以 `stale:` 开头），排队任务自动续跑，不再因为残留状态让自动抓取永久停摆。
- （v2.10）只读状态脚本 `scripts/scoreline-crawl-status.ts`：查看运行中 / 排队 / 疑似卡住任务、各来源最近状态与下次到期、最近运行记录；不写库、不打印页面正文或密钥。
- （v2.09）服务器导入脚本 `scripts/import-jilin-school-lines.ts`：默认 dry-run 只抓取并打印长春工程学院 / 长春师范大学录取表，`--write` 才落库；写前自动 `VACUUM INTO` 备份，重复执行幂等，内容全部未变时不生成新备份；数据库不存在或院校未导入时直接失败且不创建 / 迁移数据库；支持 `--ccit-html` / `--ccsfu-html` 用本地另存页面绕过 WAF。
- （v2.07）吉林校级线试点：新增长春工程学院、长春师范大学两条校级源与 `school-admit@1` 解析器，抓取官方专升本录取表后自动写入招生专业与专业最低投档分；咨询师选「院校 + 专业」即可看到最低分、计划 / 录取人数与来源。
- 分数线抓取按置信度自动收录：`confidence >= 0.70` 的结果抓完即可查询，无需人工复核。

### 变更

- （v2.11）抓取重定向改为逐跳安全校验：最多跟随 5 跳，每一跳先校验目标地址；跳转到内网 / 回环 / `.local` 地址会被拒绝且不会发出请求，循环、超跳、非法 `Location` 明确失败；生产环境拒绝 HTTPS→HTTP 降级。
- （v2.11）抓取响应限流：`Content-Length` 超过 10MB 直接拒绝；没有长度或长度不准时边读边计数，累计超过 10MB 立即中止，不再先把整包读进内存。
- （v2.11）新增抓取失败码 `blocked`：HTTP 401/403（站点拒绝非浏览器请求）不再按网络错误处理、不重试，失败提示改为「换官方 JSON / 本地 HTML / 人工核验入口」，来源与抓取记录均以 `blocked:` 开头。
- （v2.10）抓取预算：整轮 30 页不变，新增单源最多 10 页；运行时限改为每页检查，超时只停止当前来源，其他来源仍按剩余时间尝试。
- （v2.10）抓取失败重试：网络错误 / 429 / 5xx 自动退避重试 2 次（1s / 3s）；429 尊重 `Retry-After`（上限 60 秒）；403 / 404 等确定性失败不重试。
- （v2.10）原始抓取快照在启动时清理一次，并每 24 小时再清理 90 天前的快照；结构化分数线数据不受影响。
- （v2.09）分数线页面只保留查询：删除顶部说明副标题，以及「抓取队列」「覆盖看板」「立即抓取本省」三个手动入口；抓取与导入改由后台调度器和服务器脚本完成。
- （v2.08）文档入口收敛：产品说明文档（原 `docs/`，158 个文件）移出工作区，仓库外备份在 `_vesta-backups/docs-20261126-2010`（含 SHA256 清单）；后续开工先读 `PROJECT_BRAIN.md`，需求 / 设计 / 任务在 `LosAngelousDocs/`。
- （v2.08）`check:docs` 改为校验 AGENTS / CLAUDE / PROJECT_BRAIN / LosAngelousDocs 核心文件与关键指针；`check:version` 改以 `LosAngelousDocs/STATUS.md`「当前产品版本」为源，必须与 `package.json` 完全相等。原问卷设计覆盖守卫随 `docs/` 一并移除。
- （v2.07）选专科院校查询时显示「该校为专科院校，不设专升本院校线；请选择接收本科院校」，不再只显示“未收录”。
- （v2.07）产品版本升至 `2.7.0`（v2.07）；`docs/reference/` 版本快照同步到 2.7.0。
- 分数线审核口径改为自动：`confidence < 0.70` 自动标记为不展示（保留记录与来源）；同一内容重抓不改变已通过状态，低置信度新内容不会覆盖已通过的旧数据。
- 存量待处理数据在升级后首次启动时一次性按新口径处理；受影响院校的覆盖看板同步刷新。
- 覆盖看板的 `pending` 改称「历史待定」，表示仅剩历史遗留数据，不再代表有待人工复核的队列。
- 产品版本升至 `2.6.0`（v2.06）；`docs/reference/` 版本快照同步到 2.6.0。

### 修复

- （v2.11）同一页面多张表格出现重复科目时按「科目 + 是否最低分 + 最低分类型」去重，保留第一张表的值并记录 `duplicate_table_metric`（写入抓取记录备注并输出结构化日志），不再因指标唯一键报错并把整页误报成网络失败；不同值不会被静默覆盖。被站点拒绝（401/403）的抓取记录现在保留真实 HTTP 状态码。
- （v2.10）整轮抓取预算用尽时，未轮到的来源不再被标记失败或推迟一个周期，下一轮仍会正常到期。
- （v2.10）快照清理改为按批删除文件与对应记录，90 天前的记录超过 1000 条也不会留下孤儿文件。
- （v2.10）整轮时限现在同时约束单页抓取与重试退避；`SCORELINE_CRAWL=off` 时重启只清理残留状态，不再自动续跑排队任务。
- （v2.10）服务重启后 `running` / `queued` 残留不再让自动抓取永久停止；瞬时网络失败不再直接判整源失败，会按退避重试。
- 内容未变的重抓不再显示「抓取失败 / 没有抓到可写库数据」：全部批次跳过时 run 与来源状态为成功，覆盖看板保持上次结果，也不再误报「入口未核验」。
- 启动迁移在覆盖刷新失败时整体回滚（不写完成标记），下次启动会重新处理并补刷覆盖，不会出现「标记已写、覆盖未刷新」的死角。
- 小写 `b区` 写入考研国家线时自动归一为 `B区`，避免写入后按省份查询不到。
- 维度认不出的批次置信度压到自动收录阈值以下，按 `rejected` 留档，不再落入 `approved` 边界。
- 招生计划唯一键迁移改为事务执行，失败时回滚并保留旧索引，下次启动重试。

- 招生计划唯一键补上专业名称：同一院校同年同培养方式下，空专业代码的不同专业不再互相覆盖。
- 考研国家线必须标明 A 区 / B 区，避免写入后按省份查不到。
